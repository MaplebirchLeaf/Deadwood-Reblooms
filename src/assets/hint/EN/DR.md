### Entry, settings, and statistics

Open this guide from the sidebar mod hint. Select a module from the contents or search for a character, place, or feature. Search expands sections with matches. The framework module manager controls which features load; reload when it asks. Disabling the root `DR` module disables every child module.

Open **Character → Statistics → Mods Statistics** for foldouts showing this save's breakthroughs and transformations, school standing, finance and property, and character routes. Disabled child modules have no corresponding section. The journal and this guide explain the next step when a route stalls.

| Setting                  | Effect                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| Sidebar control position | Choose desktop, mobile, or hidden. Hiding the entry does not disable enabled child modules |
| Custom bodywriting       | Set the text and colour in a vanilla mirror once enabled                                   |
| Bailey rent carryover    | Refused weekly rent adds to later bills                                                    |
| Hide ear-slime parasites | Hide the visible parasites on the player image. Traits and effects remain active           |

The main wardrobe also has a clothing search field. Enter an item name and confirm to filter the current list in the chosen language. Clear the field and confirm if an expected item is missing. Rent carryover continues to affect later amounts due.
