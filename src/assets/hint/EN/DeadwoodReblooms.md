### Prerequisites

The target game version is **0.5.12.13**, with maplebirch framework **5.2.0 or later**. Install the loader's required dependencies, enable the root and desired submodules, save and reload. Character, location and story prerequisites still apply to each feature.

### First-use steps

1. Tick the desired modules. Checkboxes show saved choices, which take effect after reloading.
2. Review pending changes, save and choose Reload now. Several changes can share one reload.
3. Start at the relevant location below. Relationships, permits, funds and skills still need normal progression.
4. Check the journal and statistics after each stage before continuing. Repeatedly entering a location does not force an unlock.

### Toggles, saves and reloads

Disabling the root disables its submodules. Disabling a parent disables dependants, and enabling a child enables required dependencies. Re-enable the root through framework module management.

Module choices belong to this browser's framework settings rather than each individual save. Save-specific music and other options remain separate. Disabling a module does not undo past stories or remove every saved record.
