### Where portraits appear

When vanilla already displays a supported NPC in a scene or sidebar character area, this module draws the matching portrait. Robin, Sydney, Kylar, and Whitney have clothing, pose, and story-state variants; other connected characters use their own scene-specific outfits. The module does not change schedules or summon someone who is absent.

**Small Social-card avatars belong to MLIANPCA**, using different assets. If a Social card has an avatar but the current scene has no portrait, check that vanilla actually displays the NPC there and that NPCSidebarPortrait is enabled. If one outfit variant is missing, check another scene for its default look.

This module adds no relationship or story unlock. For character routes, use the Robin, Sydney, Whitney, or Kylar guide and the game journal.
