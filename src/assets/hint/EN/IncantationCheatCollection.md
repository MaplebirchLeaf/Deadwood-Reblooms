### Create, find, and run a command

Open framework **Content → Cheating Collection**. Enter a name and code. Code starting with `<<` is saved as Twine; other code is saved as JavaScript. Click its name to edit it or “Execute” to run it against the **current game state**. Search filters by name. Sort cycles through orders, while favourites appear first.

Unstar a favourite before deleting it. Export produces a `.cheat` file. Import reads that format and **replaces the entire command library**. The collection lives in browser **IndexedDB**, so different game saves share the command library. Story-variable changes caused by executing a command still belong to the current save. Export the file to move the library to another device.

This is separate from the vanilla cheat menu and unlocks no character story. Check a command and the active save before running it, especially if it edits `V` or time.
