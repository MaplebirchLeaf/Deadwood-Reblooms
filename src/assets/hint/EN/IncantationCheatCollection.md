### Save frequently used commands

Open **Framework Content → Cheat Collection**, enter a name and command, then create an entry. Commands beginning with `<<` run as game macros; other commands run as JavaScript.

- **Execute** immediately affects the current game. Save your progress first.
- Click a name to edit it. Search filters names, and the sort button changes the order.
- Star entries to keep favourites at the top. Remove the star before deleting an entry.

### Back up and import

Export creates a `.cheat` file. **Import replaces the entire command collection**, so export a backup before importing another file.

The collection is stored in the current browser and shared by your game saves. Import it manually when changing browser or device. Commands act on the currently loaded game.
