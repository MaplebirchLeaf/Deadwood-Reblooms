# Deadwood Reblooms · Game Guide

Use the contents below to jump to a module's entry points, requirements, actions, and checks when progress stalls. All sections remain visible on one page. Character routes follow vanilla schedules, and the journal records your current step. **Character → Statistics → Mods Statistics** shows breakthroughs, school, property, and character-route progress for the current save.

Search for a character, location, or feature to jump to the first result. Enable modules in the Maplebirch Framework manager and reload when prompted. `DR` is the root module; disabling it disables the whole mod.
