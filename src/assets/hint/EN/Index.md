# Deadwood Reblooms · Game Guide

Choose a module below. Each page lists the actual entry point, requirements, actions, and checks when progress stalls. Character routes follow vanilla schedules, and the journal records your current step. **Character → Statistics → Mods Statistics** shows breakthroughs, school, property, and character-route progress for the current save.

Search for a character, location, or feature to open the matching module. Enable modules in the Maplebirch Framework manager and reload when prompted. `DR` is the root module; disabling it disables the whole mod.
