### 前置条件

游戏目标版本为 **0.5.12.13**，秋枫白桦框架至少 **5.2.2**。按加载器要求安装依赖后，启用枯木逢春根模块及要使用的子模块，保存游戏并重载。各子模块的剧情还要分别满足人物、地点与进度条件。

### 指南、设置与统计在哪里

| 入口                   | 能做什么                                         | 不会替你完成什么             |
| ---------------------- | ------------------------------------------------ | ---------------------------- |
| 侧边栏模组提示         | 搜索指南、跳转章节、修改模块开关                 | 不自动完成剧情与解锁         |
| 模组设置               | 调整租金、图像、音乐、遭遇战等选项               | 不是所有人物互动的入口       |
| 角色 → 统计 → 模组统计 | 查看属性、转化、校园、金融与人物路线的已记录进度 | 不能代替交表、邀请和任务步骤 |
| 游戏日志               | 查看下一步线索、账单与路线状态                   | 不会让缺席的人物立即回家     |

### 第一次使用怎么做

1. 在指南中勾选要使用的模块。勾选状态表示保存的选择，当前游戏要重载才按新选择运行。
2. 查看待重载条目，先存档，再点击「立即重载」。一次调整多个模块后可统一重载。
3. 根据下表到实际地点开始。尚未达标的角色关系、许可、资金和技能仍要正常推进。
4. 一阶段完成后看日志与统计，确认记录，再进行下一阶段。不要只反复进出地点等待入口出现。

| 想做什么               | 先读哪章             | 从哪里开始                         |
| ---------------------- | -------------------- | ---------------------------------- |
| 选择多位恋人           | 更多恋人与社交栏头像 | 角色 → 态度，先检查意识与候选资格  |
| 经营罗宾摊位与店铺     | 罗宾拓展             | 海滩柠檬水摊、公园热巧克力摊       |

| 惠特尼救援与日常       | 惠特尼拓展           | 地下牢房，或已解锁的码头／公寓互动 |
| 凯拉尔留宿与生活       | 凯拉尔拓展           | 已完成首次借宿的庄园               |
| 校园身份与健身         | 模拟人生             | 校长办公室、峭壁街健身房           |

| 立绘、音乐与作弊       | 各界面模块           | 模组设置、原版场景或框架内容页     |

### 基础设置的效果

| 设置                 | 怎么用                       | 效果与限制                               |
| -------------------- | ---------------------------- | ---------------------------------------- |
| 侧边栏控件位置       | 选桌面端、移动端或隐藏       | 隐藏提示入口不等于关闭模块               |
| 定制涂鸦             | 开启后到原版镜子界面         | 设置身体刻字内容与颜色                   |
| 贝利租金累积         | 在模组设置开启               | 拒付的周租会累积到后续账单，增加以后负担 |
| 隐藏耳部史莱姆寄生物 | 在模组设置开启               | 只隐藏外观，寄生状态与特质仍生效         |
| 衣柜搜索             | 在主衣柜类别中输入名称并确认 | 按当前语言筛选，清空并确认恢复列表       |

### 开关、存档与重载

根模块关闭会停用本模组的子模块。关闭上级时依赖它的模块也会关闭，启用子模块会启用必要依赖。需要重新启用根模块时去框架模块管理。

模块开关保存在当前浏览器的框架设置中，不是每份存档独立一套。音乐启用等存档内选项仍要另行检查。关闭模块不会撤销已经发生的剧情，也不等于从存档删除全部相关记录。

<span class="teal">重载前先保存。未保存的游戏进度会丢失。</span>本指南包含解锁条件与后续结果，阅读人物和成就段落会涉及剧透。

### 入口缺失时怎么查

按 **模块与重载 → 实际地点 → 人物日程 → 前一阶段 → 关系／技能／资金 → 时段与天气 → 每日次数** 的顺序核对。遇到报错，提供游戏、框架和模组版本，具体入口、点击前后文字与完整报错。
