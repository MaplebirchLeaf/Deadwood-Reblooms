### 入口、设置与统计

在侧边栏的模组提示打开本指南。目录可跳到对应模块，也能直接向下阅读。顶部搜索框可按角色、地点或功能定位结果。目录复选框与框架模块管理共用模块开关，修改后重载生效。关闭根模块 `DeadwoodReblooms` 会停用所有子模块。

打开**角色页 → 统计 → 模组统计**，按折叠栏查看当前存档的属性突破与转化、校园身份和评价、金融房产、人物路线。关闭的子模块不列对应栏。统计页只读取存档中的进度，不能替代角色剧情中的下一步提示，路线卡住时还要查看日志与本指南。

| 设置                 | 实际效果                                                           |
| -------------------- | ------------------------------------------------------------------ |
| 侧边栏控件位置       | 可选桌面端、移动端或隐藏模组提示入口。隐藏入口不关闭已启用的子模块 |
| 定制涂鸦             | 开启后，在原版镜子界面设置身体刻字的文字与颜色                     |
| 贝利租金累积         | 每周拒付的租金会加入后续账单                                       |
| 隐藏耳部史莱姆寄生物 | 仅隐藏角色画面上的寄生物，特质和效果仍生效                         |

主衣柜还增加了服装搜索框。在衣柜类别里输入服装名称并确认，当前列表会按所选语言筛选。找不到物品时，先清空搜索框再确认，检查是否被名称过滤。房租累积会持续影响以后应付金额。

### 开关与重载

**勾选／未勾选表示保存的模块选择。**修改后，页面会列出待重载的模块。可继续调整，最后点「立即重载」。关闭上级会同时关闭依赖它的模块，启用子模块会启用所需依赖。`DeadwoodReblooms` 是枯木逢春的根模块，关闭它会关闭本模组的所有子模块。重载后可从框架模块管理重新启用。

模块开关保存在当前浏览器的框架设置中，作用于此安装下的游戏存档。它和「动态音乐启用」等存档内设置是两层控制。切换模块不会撤销已经发生的剧情或清空人物进度。**重载前先保存游戏**，未保存的游戏进度会丢失。

### 阅读与排查

搜索角色、地点、功能或条件，会高亮正文中的匹配文字并跳到第一个结果。清空恢复全文。人物章节包含解锁条件和后续剧情，可能涉及剧透。

先确认模块已启用且完成重载，再查人物日程、天气、关系、资金及每日限制。**角色页 → 统计 → 模组统计**查看当前进度，日志指引剧情下一步。正文中的价格与条件以对应游戏分支和实际场景为准。
