# 使用说明

需要游戏 **0.5.12.13及以上**、秋枫白桦框架 **5.5.6及以上**，以及加载器列出的其他依赖。

在指南目录勾选想玩的模块，保存游戏后重新加载。关闭父模块会关闭依赖它的子模块，启用子模块会一并启用所需依赖。模块开关保存在当前浏览器，人物进度和资产保存在存档中。

## 去哪里查看

| 入口              | 用途                                     |
| ----------------- | ---------------------------------------- |
| 侧边栏 → 模组指南 | 查找玩法、条件，搜索章节或开关模块       |
| 设置 → 模组设置   | 调整界面、租金、音乐与遭遇选项           |
| 日志              | 查看当前委托、账单、车辆位置和剧情线索   |
| 统计 → 模组统计   | 查看已完成的里程碑、收入和累计记录       |
| 原版作弊面板      | 调整已启用模块的资金、车辆、弹药和库存等 |

## 常用设置

- **侧栏按钮位置**：可选桌面、移动端或隐藏。
- **自定义身体文字**：启用后到原版镜子设置文字与颜色。
- **移动端状态条与回退按钮**：在收起的侧栏查看属性或返回上一页。
- **贝利租金累积**：启用后，未交的周租会计入后续账单。
- **隐藏耳内史莱姆**：只隐藏显示，不移除寄生状态或效果。
- **衣柜搜索**：在衣柜分类输入当前语言的衣物名称并确认，清空后再次确认可恢复列表。

作弊面板中的数字调整即时生效。银行余额调整会计为作弊收入，果园库存不能低于已预留数量，行程中不能修改车辆油量与车况。

## 找不到选项时

先确认模块已启用并重新加载，再检查地点、人物日程、前置剧情、好感或技能、钱款、时间天气，以及当天次数。具体要求见对应章节。

反馈报错时，请附游戏、框架和模组版本、出现问题的地点、点击前后的情况，以及完整报错。
