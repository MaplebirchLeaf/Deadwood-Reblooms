### 从两处摊位开始

在海滩柠檬水摊或冬季公园热巧克力摊，问罗宾摊位设备的事。看到经营问题后，回**孤儿院 → 罗宾房间**商量改造。每次升级后，再去对应摊位问起设备，才会有下一步的改造计划。

每处第一次升级<span class="gold">£600</span>，第二次<span class="gold">£400</span>，两摊都升满共<span class="gold">£2,000</span>。可以借出PC现金，也可让罗宾用留足房租后的资金支付。PC出资会记为罗宾的借款。

升级后有新品与防雨棚，可试喝或帮工。帮工每天一次、45分钟，罗宾需在场并能正常活动。营业增收记入储备金，用于房租和改造。罗宾送给PC的钱从个人现金支出。账本另记欠PC的借款，动用资金前仍会留出下期房租。

罗宾出门或睡着时，也可以在房门口悄悄留下 **£20、£50 或 £100**，帮罗宾攒钱。款项直接计入现有储备金，不记为借款。罗宾没有看见是谁留下的，因此不会立刻增加好感。同住后不再向孤儿院的旧房间留钱。

### 家教

至少升级一个摊位后，在孤儿院看家教告示，回房间商量，罗宾的主见达到 **45** 后才会正式开班。

试教与后续上门在**多瑙河街**。学期内周二、周四17:30–18:30可陪同，累计六次授课后加周五。真正完成帮课，PC得到<span class="gold">£7.50</span>，罗宾营业储备增加<span class="gold">£8</span>，罗宾也可自行上课。上门后直接离开不算完成授课。

### 峭壁街饮品店

两摊都升到第二级后，回房间商量正式开店，再按日志办理：

共同办理前，先在**不上学的一天、罗宾实际在家有空时**约好当天见面。周末可趁 **07:00–09:00** 出摊前商量，再自行走到市政厅或峭壁街空铺。约定当天有效，不会挤掉已有活动。主见足够、本人有空且能在关门前回来时，仍可独自申请、看铺或领证。

市政厅申请和领证在 **09:00–17:00** 办理。进门后还要选**排队等候**，到柜台才有办理选项。排队需20分钟，申请还需20分钟，别赶着关门才到。验店当天不能领证，要等第二天。

| 顺序 | 操作                     | 费用                             |
| ---- | ------------------------ | -------------------------------- |
| 1    | 市政厅申请               | <span class="gold">£500</span>   |
| 2    | 峭壁街落实店面           | <span class="gold">£1,500</span> |
| 3    | 店铺检查，不早于申请次日 | <span class="gold">£1,400</span> |

开店合计<span class="gold">£7,400</span>，另算摊位升级。已开户、持借记卡且存款足够时，开店期间可从PC存款借给罗宾一次<span class="gold">£2,000</span>，仍记入借款。

开业后从**峭壁街 → 罗宾饮品店**进入，营业09:00–21:00，获得「蜜雪冰城」。罗宾不在时也可能有代班人员，陪伴与试喝要等罗宾在店。

### 补货、员工与副业

- **店内帮工**：每天一次，用一箱新品原料，PC得到<span class="gold">£10</span>，营业储备增加<span class="gold">£20</span>。三箱用完后补货<span class="gold">£30</span>，数学能力足够可降至<span class="gold">£25</span>。
- **正式员工**：最多两名，外来店员与孤儿院同伴共用名额，每人培训费<span class="gold">£350</span>、周薪<span class="gold">£350</span>。应聘者与班表会保留，可在账本查看。
- **孤儿院同伴**：上学日16:00后谈聘用，当班且尚未熟练时，可每天帮罗宾培训半小时。同伴按经验提高销售，工资已算入周账本。
- **鲜花与爆米花**：开业后分别花<span class="gold">£100</span>设鲜花柜台、<span class="gold">£150</span>装爆米花机。鲜花需补货，爆米花仍受原版随身数量限制。
- **气球**：先在海滩推进气球摊合作或比赛，再设店内批发。比赛每天一次，三次胜利可推进和解。
- **水果供货**：果园开放后，与罗宾商量柠檬或橘子订单，详见果园章节。

### 房租与共同反抗

两摊升满后，收入、主见与创伤状态达标，可以结清旧债，让罗宾自己负担房租。之后再商量两人的租金，实际付款在贝利收租时选择，仍需留足罗宾自己的下一期房租。

| 目标     | 主要准备                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 自己交租 | 周收入至少<span class="gold">£1,500</span>，并足够覆盖当期房租与缓冲，主见60、创伤不高于40，资金足够结旧债 |
| 共同交租 | 周收入至少<span class="gold">£5,000</span>，租金更高时要求也提高，主见80、好感60、创伤不高于30             |
| 协同反抗 | 已自己交租，周收入至少<span class="gold">£4,000</span>，主见85、创伤不高于30，先在房间商定计划             |

共同反抗从下一次贝利收租进入实际战斗。两次胜利后联络孤儿，三次后推进团结，四次与原版连续击败贝利进度都满足后，按大厅与日志完成最终对峙。战败可能加重罗宾创伤。

贝利离开孤儿院后，学校表格的监护人签名改到倒钩街公寓办理。

### 病院与两条救援出口

严重创伤持续多日会先出现警告，再可能被收容，及时关心与缓解创伤有助于中断恶化。住院后相应经营暂停。

- **院内计划**：PC也已住院、白天可自由活动时，在07:00–21:00前找罗宾。分两个不同日期商量计划，准备哈珀门禁卡，等合适的睡眠阶段共同逃离。失败会失去门禁卡并退回准备阶段。
- **触手平原**：取得原版增强的最高异种癖特质后，进入触手平原寻找罗宾，每天一次，不要求PC住院。带罗宾穿过平原，找到森林出口才完成救援，返回病院门可能被抓。沿途仍有遭遇，压力到顶会失败。

成功后罗宾进入恢复期，要等创伤不再严重才恢复正常生活。救援不会立刻消除创伤。

### 相处与校园联动

海滩钓鱼约会需要罗宾在场、关系允许、可用鱼竿与合适天气，09:00–16:00前每天一次。一级柠檬水摊可花<span class="gold">£30</span>配置烤架，先分享鱼学会配方，再按每日上限出售。

实际流星雨之夜、无雨、20:00后可提议观星。普通游泳、店内陪伴和起床提醒各看人物日程与关系。风纪委员或学生会长可在罗宾店每天订一次学生会饮品，银行付款<span class="gold">£20</span>，改善学生声望和教职工信任。
