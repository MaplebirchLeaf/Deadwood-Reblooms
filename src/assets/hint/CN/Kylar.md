### 取得再次留宿的邀请

先完成原版的首次庄园留宿事件，并在态度页把凯拉尔选为恋人。凯拉尔能够正常活动时，18:00后到庄园卧室，询问「以后能否留宿」，白天则要等凯拉尔确实在卧室。

获邀请后可使用衣柜、镜子与床铺，选择睡衣或睡眠时长。庄园原有事件仍会发生，夜间对白看凯拉尔是否在场，不是每天固定触发。

### 日常相处

| 地点 | 可以做什么                                                                 |
| ---- | -------------------------------------------------------------------------- |
| 卧室 | 每天一起玩一次游戏、整理一次笔记，修补与核对习题需要相应语文能力           |
| 厨房 | 每天泡茶一次，凯拉尔不在时也可自己喝                                       |
| 花园 | 获留宿邀请后，08:00–09:00前、没有上课安排时找凯拉尔，帮忙或回应担忧        |
| 浴室 | 18:00–23:00前可能遇见凯拉尔，可洗浴或隔门回应                              |
| 公园 | 原版关系已允许公开画你时，每天问一次「在画什么」，等待展示、称赞或停止追问 |

这些选择会带来不同对白、好感与压力变化。做笔记和帮忙需能活动的手臂，花园相处还要求衣着合适。校内身份会改变部分谈话，但不替代学习能力。

### 庄园留宿与自家同住

邀请凯拉尔搬进自购房，按金融章节的住宅流程办理。搬家后部分陪伴转到新家。嫉妒仍会影响相处和增加同住者的邀请，留宿许可不会消除这些关系限制。
