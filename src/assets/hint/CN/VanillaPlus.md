### 前置条件与入口

启用「原版增强」并重载。属性突破的具体条件见下文，医院服务从医院大厅查看。银行、证券、贷款、房产与阿德里安由独立的「金融系统」模块提供；自住房的诡异镜面需要同时启用两个模块。

### 六项属性突破

意志、体格、容貌、暴露癖、异种癖、淫荡度在达到原版上限并完成专属剧情条件后，才可继续进入第七级。突破后继续提升到新上限，才获得对应特质。六项都完成还有总成就。角色页与日志显示当前进度。

| 属性   | 突破前具体要完成什么                                                                                                                            |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 意志   | 原版意志到上限，并让两耳都寄生史莱姆。完成湖底监狱**附身抗拒成功**、分裂结局、神殿守夜最后一小时。幽灵监狱须处于恢复阶段，调查进度到第 4 步     |
| 体格   | 原版体格到上限。完成公寓潜入的体格或战斗结果，推进艾利克斯农场袭击到第 12 阶段，经历相关农场群战或货车战，再从收容所脱困                        |
| 容貌   | 原版容貌到上限。户外基础魅惑与模特名声均达到突破要求。检查突破时卸去全部化妆、美瞳与面罩                                                        |
| 暴露癖 | 原版暴露癖到上限。裸泳课程累计至少 **5 次**，在艾弗里宴会获得舞厅裸舞成就，并完成商业街拍摄的成功裸奔，传单至少 **250** 张                      |
| 异种癖 | 原版异种癖到上限。在格威岚路线取得野歌，净化进度达到突破要求，与格威岚的性爱与野兽约会次数各至少 **3**，再亲自主持封印成功且净化进度达标 的仪式 |
| 淫荡度 | 淫荡度、暴露癖、异种癖都达到各自原版上限。不要求三者先分别拿到七级特质                                                                          |

意志、体格、容貌突破后新上限为原上限的 **125%**。暴露癖、异种癖、淫荡度的新上限为 **150%**。如果装有会改变原版上限的模组，以游戏内实际原上限为基准。突破条件完成后仍要继续提升到新上限，才会取得特质。

暴露癖第七级特质允许在镇上裸行，前提是 PC 对相应裸露程度已不再感到不适。原版露出、名声与遭遇后果仍会发生。异种癖特质与诡异镜子联动：先接触相应镜子，凌晨 **03:00** 开启触手设置，幻觉至少 2 级或满足当日镜面触手条件，才能进入触手平原。**每次进入都重新随机出口坐标**，不同镜子也可能落在同一格。手部与多人遭遇战动作仍受人数、身体部位占用和原版战斗条件约束。医院还有独立的童贞修复服务。

### 嗜虐

**解锁条件**：启用「原版增强」，并在**当前存档**获得原版成就「施虐受虐狂」。该成就要求施虐与受虐同时达到各自的最高等级，成就资格仍按原版规则判断。已经获得成就的存档会直接显示<span class="def">嗜虐</span>，不需要额外事件。

**效果**：<span class="def">施虐与受虐倾向不再每日自然衰减</span>，正向增长、等级结算与其他剧情变化仍按原版处理。特质不直接增加倾向数值，也不恢复剧情或其他效果主动扣除的数值。

**开关**：不依赖催眠设置。停用「原版增强」后恢复正常衰减，重新启用后按本存档的成就记录生效。

### 三位一体

**前置条件**：启用「原版增强」，并开启游戏设置中的神圣转化。先在神殿祈祷室祈祷，分别遭遇原版的温暖存在、岩石接触与空无黑暗。每种都要亲身遇见，选择接受或挣脱都会记录本次接触。堕天使转化须达到**稳固阶段**，祈祷时佩戴**暗黑吊坠**。

**触发地点与时机**：三种接触齐全后，在日蚀期间佩戴暗黑吊坠，使用祈祷室门口原版的「偷偷溜进去」选项进入并祈祷。该入口需要满足原版历史等级要求，并扣除恩典。每次祈祷有 **10%** 的机会遇到新的异常，日蚀必须在这次祈祷结束时仍在持续。

**如何选择**：异常中选择「放开心神，拥抱这一切」会进行原版意志判定。较高意志更容易保持清醒，判定难度显示在选项旁。即使成功，PC 仍会承受疼痛、压力与创伤，并增加意识，随后获得「三位一体」。失败会造成更重的冲击并降低自控，可以在之后的日蚀重新尝试。选择「摆脱这种感觉」可以退出，增加少量压力、意识与意志。

**特质效果与镜子操作**：「三位一体」允许天使、堕天使与恶魔共存，并阻止三者的成长点数衰减。点数获取条件与转化副作用沿用原版。尚未获得的形态仍需自行培养，已有形态会同时显示在镜子的原版设置中。

### 诡异镜子：进入与返回步骤

1. 先完成异种癖突破，并继续提升到取得对应第七级特质。只有满足突破剧情但尚未获得特质时不能使用这条路线。
2. 在想使用的镜子处接触镜面，登记该镜子。可涉及孤儿院、自住房、农场、高塔、神殿及人物住所，人物住所仍需要自己的进入许可。
3. 游戏时间凌晨 **03:00–04:00 前**，开启触手设置，并达到幻觉二级或满足当日镜面触手状态，再检查穿过诡异镜面的入口。
4. 进入后看平原里的镜面提示与出口，不要把触手平原当成无风险的固定传送大厅。每次进入会重新分配镜子坐标。
5. 从与进入点不同的镜子返回现实可取得「镜子的另一边」。同一坐标附近有多面镜子时，以实际选择的出口为准。
6. 从平原里的入口镜子离开或在平原内昏倒，会**返回进入时的那面镜子**。因分娩昏倒仍按原版镜子入口流程送往医院。

镜面另一侧仍是触手平原，原版危险与遭遇继续生效。没发现某面镜子、没有对应住处许可或当前时间不对，都不能靠已有另一面镜子的记录来代替。

### 医院服务

**童贞修复**在医院大厅检查可用项目，每项 £1,000、约一小时。项目根据相应身体状态和贞操装置限制开放，只恢复对应身体记录，不会删除已经发生的关系与剧情经历。
