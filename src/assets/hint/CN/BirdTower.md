### 前置条件

启用「高塔扩展」模块。它为原版的巨鹰与鹰崽内容补充成长、喂食、性格与狩猎玩法，内容发生在鹰塔与荒原。取得巨鹰的信任，在塔里孵出并养育小鹰后，随成长推进。

### 成长阶段

小鹰按年龄分为五个阶段：

| 阶段     | 年龄      | 说明                                       |
| -------- | --------- | ------------------------------------------ |
| 孵化     | 0–13 天   | 刚破壳，身上没有羽毛                       |
| 留巢     | 14–34 天  | 长出绒羽，仍然留在巢中                     |
| 离巢     | 35–64 天  | 长出稚羽，可以离开巢，但还不会飞           |
| 初次飞行 | 65–89 天  | 羽翼褪去绒毛，开始学习飞行                 |
| 初次狩猎 | 90 天以后 | 长出完整飞羽，学习自行狩猎，搬去单独的新巢 |

阶段推进时，进塔或上栖木会依次播放换羽、初次飞行与初次狩猎的事件，巨鹰会亲自教小鹰飞行和狩猎。已经过去的阶段不会回滚，一次推进多天也会保留跨过的成长提示。

### 日常互动

查看孩子（Childrens Home）时，小鹰会根据年龄、性格和当时巨鹰的状态显示不同的日常活动，包含休息、理毛、乞食、探索、练习飞行、观察天气与跟随亲鸟等。活动沿用原版的刷新间隔，巢里的日常事件每个地点每天最多触发一次，结束后返回原来的页面。

### 喂食

小鹰的食量随年龄增长。留巢期一只潜伏者可以喂饱所有孩子，离巢后每只小鹰每天要吃两顿，学会单独狩猎后不再需要玩家喂食。

- 把潜伏者带回塔里时可以按只喂给指定的孩子，也可以平均分配。
- 喂食次数会累积，幼年额外喂食可以促使体型增大。现有体型与累计喂食量都会轻微影响性格的随机结果。
- 玩家当天没有进入鹰塔时，未受伤、未怀孕的巨鹰会自行喂养小鹰，照样计入累计喂食次数。

### 性格特质

小鹰在 65 天时会随机获得一种性格特质，参考原版狐狸的特质系统：

| 性格          | 倾向                                                       |
| ------------- | ---------------------------------------------------------- |
| 笨拙 clumsy   | 动作笨拙，学得慢，喜欢和亲鸟贴贴，狩猎偏好垃圾             |
| 同情 sympathy | 擅长和各种生物社交，喜欢探索世界，狩猎偏好其它目标         |
| 聪明 clever   | 学说话更快，更自我中心，喜欢收集闪亮亮，狩猎偏好贵重物品   |
| 强势 dominant | 领地意识强，个头大，干架猛，喜欢狩猎和干饭，狩猎偏好潜伏者 |

性格决定狩猎时的偏好加成，也会让日常互动、成长事件与和小鹰一起狩猎的随机事件出现不同的反应。

### 随行狩猎

学会飞行与狩猎的小鹰会主动出门狩猎。

- **自行狩猎**：小鹰会在荒原自行捕猎。玩家在荒原深处旅行时，有概率遇见正在狩猎的小鹰，并触发三种随机事件之一。
- **请求同行**：玩家独自狩猎时，小鹰有概率从身后追上来请求一起去。带上孩子后，狩猎中出现的事件与文本与和巨鹰同行时不同，结束时会按性格分配带回来的战利品。
- **新巢**：学会狩猎的亚成年小鹰要搬去单独的新巢。塔内会出现建巢的提示，建成后可以查看孩子的巢，并在升级菜单里继续改造。

本模块还新增了三个成就：**雏鹰展翅**（见证小鹰的初次飞行）、**前兽出没**（和小鹰一起击退荒原的野兽）、**与狐共舞**（见证一段跨物种友谊）。

### 找不到入口或没有反应

先确认模块已启用并已重载。成长事件需要小鹰达到对应年龄，并且当次进塔或上栖木时满足天气与巨鹰状态的条件。没有触发时下次再来通常就会播放。喂食只接受巢里的潜伏者，数量不足时可以选择平均分配或逐只喂养。请求同行只在玩家独自狩猎时随机出现，每天最多一次。
