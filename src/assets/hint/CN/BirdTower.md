### 从鹰塔开始

取得巨鹰的信任，在鹰塔孵出并养育小鹰。「高塔扩展」增加小鹰的成长、性格、喂食与随行狩猎，进入鹰塔或上栖木时，会遇到相应成长事件。

| 年龄    | 阶段                       |
| ------- | -------------------------- |
| 0–13天  | 刚破壳，尚未长羽           |
| 14–34天 | 长出绒羽，留在巢中         |
| 35–64天 | 可以离巢，尚不会飞         |
| 65–89天 | 学习飞行                   |
| 90天起  | 学习独自狩猎，准备搬进新巢 |

### 照料小鹰

- 在查看孩子时观察日常活动与饥饿情况，再把带回塔里的潜伏者喂给它们。
- 留巢期一只潜伏者可喂饱所有孩子，离巢后每只小鹰每天需要两顿。可以指定孩子，也可以平均分食，食物不够时稍后再补。
- 正常供食维持成长，额外喂食才有助于增大体型。会自行狩猎后不再需要你每天喂养。
- 换羽、初飞与初猎会随年龄推进。天气或巨鹰当时的状态不合适时，改天回塔查看。

### 性格与狩猎

65天时，小鹰会获得一种性格：**笨拙**偏好垃圾，**同情**偏好探索其他目标，**聪明**偏好贵重物品，**强势**偏好潜伏者。性格也会改变日常对白与狩猎反应。

学会狩猎后，小鹰会自己到荒原捕猎。你在荒原深处可能遇见它们，独自出猎时，也可能遇到孩子请求同行。带它们出门后，留意随机事件，返程时再分配战利品。

小鹰独自出猎时，只有你留在鹰塔、荒原或城堡，狩猎时间才会推进。可以分几次短暂活动等它们回来。

陪小鹰完成初飞与初猎后，获得**驯鹰人**。有小鹰同行时，战利品携带上限额外增加1。

塔里出现建巢提示后，按升级菜单建造并改进孩子的新巢。可以继续前往查看。

### 成就

**雏鹰展翅**：见证初次飞行。**前兽出没**：和小鹰击退野兽。**与狐共舞**：见证小鹰与狐狸的友好互动。
