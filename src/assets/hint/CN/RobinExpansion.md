| 进度         | 入口与操作                                                                                 | 卡住时检查                                                           |

| 营业与新品   | 在当日摊位帮忙营业。第一次改造后试饮 £2 新品，第二次增加口味                               | 新品试饮每天一次。营业班次看罗宾当日安排                             |
| 家教         | 至少改造一处摊位、罗宾支配欲达到 45，在孤儿院看到家教启事，回房间提出建议                  | 多瑙河街的试课在放学后。PC 可陪同，也可让罗宾独自授课                |

改造费可以由罗宾从营业储备金支付，也可由 PC 先借。罗宾会预留下一周的房租，借款会进入账本，不会当成赠礼。支配欲、创伤、储备金决定罗宾能否独自完成部分手续。开业后 09:00–21:00 从峭壁街进店，采购新品原料、轮班、试饮并核账。开店时解锁**“蜜穴冰城”**成就。

| 费用节点                   |                   所需资金 | 何时能推进                                                |
| -------------------------- | -------------------------: | --------------------------------------------------------- |
| 任一摊位第一次、第二次改造 |                 £600、£400 | 先在该摊位看到问题，再回罗宾房间商量。PC 可付现金作为借款 |
| 市政厅申请、看铺、检查     |       £500、£1,500、£1,400 | 按日志顺序进行。检查至少在申请次日，领许可至少在检查次日  |
| 店铺设备与开业原料         |                     £4,000 | 领到许可后在峭壁街办理                                    |
| 新品原料补货               | £25，数学低于 300 时为 £30 | 店铺原料箱用完且罗宾在店时补 3 箱                         |

罗宾储备不足时，可在账本里从**已开户的银行账户借给罗宾 £2,000**，这笔钱进入营业储备并记为他欠 PC 的债。罗宾的可用资金仍须留出下一周自己的房租。独自采购摊位设备要求支配欲至少 55、创伤低于 60，后续独自办店手续要求更高的支配欲和低于 50 的创伤。

### 房租、危机与日常

先在罗宾房间谈清旧欠和罗宾自己的房租，再讨论分担 PC 的房租。看账本可以核对周收入、储备金和借款。收入或储备不足时，先升级摊位、工作或帮助其他孤儿。高创伤时先在房间关心罗宾。罗宾被送往精神病院后，去森林中的病院探望并推进营救。准备与其他孤儿反抗贝利时，按日志提示在孤儿院继续路线。

日常互动包括房门便条、夜间敲门和上学日前叫醒。罗宾是否愿意独自处理事务，取决于当时的自信、创伤和业务进展。贝利退出孤儿院后，相关学校许可要去倒钩街公寓找他。若使用 DoLP 并曾向贝利预存房租，终局会退还尚未用掉的押金。

### 约会与工作中的亲密互动

流星雨夜 20:00 后、天气干燥且罗宾好感至少 20，可以在罗宾房间或海滩约看流星。海滩有罗宾在场、天气合适时还可一起游泳。这些约会每天各有限制，可能受罗宾的创伤与剧情影响。

成为罗宾恋人、罗宾创伤低于 50 后，可以在四处进入**可拒绝的合意互动**：

| 地点         | 出现条件                                                  | 场景                                                           |
| ------------ | --------------------------------------------------------- | -------------------------------------------------------------- |
| 柠檬水摊     | 摊位至少改造一次，罗宾在海滩营业，天气不下雨，09:00–17:00 | 在推车下与罗宾亲近。罗宾仍接待客人，顾客靠近会改变战斗中的提示 |
| 热巧克力摊   | 摊位至少改造一次，罗宾在公园营业，09:00–17:00             | 在柜台下与罗宾亲近，营业和顾客动静仍继续                       |
| 峭壁街饮品店 | 已开业、罗宾在店，19:00–21:00                             | 由店员照看柜台，与罗宾进储藏室                                 |
| 流星雨约会   | 看完当晚流星后，仍是恋人且创伤低于 50                     | 由 PC 决定是否继续留在毯子下                                   |

每处先有明确的继续或离开选择。结束后返回相应街道或摊位，店铺若已关门则回峭壁街。

### 与学校联动

成为风纪委员或学生会长后，店里有新品原料、罗宾在店且银行账户有 £20 时，可每天订一次学生会饮品。款从银行扣，罗宾的营业储备增加，同时提升学生声望与教职工信任。
