### 前置条件与入口

启用「天体异象」并重载，在 **模组设置 → 天体异象** 分别启用日蚀与流星雨。没有技能或人物关系前置，两个事件各自开关。

### 怎么观察、如何等到事件

1. 确认对应开关开启，只开日蚀不会同时开启流星雨。
2. 根据游戏日期与时段观察天空、天气图标及描述。安排使用存档种子，不看现实电脑日期。
3. 当前日期没有安排时正常推进游戏，不靠反复读同一天存档刷新。
4. 事件出现后再检查相关人物联动，人物条件仍另行判断。

| 事件   | 时段与安排                                                         | 画面与联动                               |
| ------ | ------------------------------------------------------------------ | ---------------------------------------- |
| 日蚀   | 接近新月的日期才进入候选，通常 07:00 或 08:00 开始，持续 9–11 小时 | 天空、天气图标与阶段描述变化             |
| 流星雨 | 按存档日期安排，通常 20:00–22:00 开始，持续 5–7 小时，可跨午夜     | 夜空与描述变化，罗宾约会读取当晚实际状态 |

### 约会与音乐需要什么

罗宾观星需要其拓展模块、合适关系、当晚在相应地点且无雨。流星雨只是其中一个条件，不会强制把罗宾召回。

对应配乐还需动态音乐模块、播放开关及含曲目的音频包。天体异象本身不携带音频。

### 效果与限制

增加按游戏日历安排的异象，不保证每天发生，也没有通过剧情按钮随时手动召唤的入口。同一天同一存档的安排不会因为读档重新抽取。原版普通血月与这里的日蚀开关不同。

### 没看到事件时

检查相应开关、重载、游戏日期及活动时段。天空正常并不必然是故障，可能当天没有安排。只缺约会时查人物章节，只缺声音时查动态音乐章节。
