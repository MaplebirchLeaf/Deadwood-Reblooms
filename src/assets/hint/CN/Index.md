# 枯木逢春（Deadwood Reblooms）· 综合游玩指南

欢迎来到《枯木逢春》。本模组致力于在深度契合原版 Degrees of Lewdity 世界观与叙事风骨的前提下，为游戏拓展更为丰富厚重的生活模拟、日常陪伴、城镇经营、出行交通与超自然异象内容。

你可以随时在侧边栏点击模组提示打开本指南，或利用上方的搜索栏快速检索特定的角色、建筑、机制与任务。

### 游玩与追踪提示

- **任务与线索追踪**：正在进行的事件阶段、待结算的商业账单与下一步行动指引，均可在游戏的【**日志（Journal）**】中随时查看。
- **累计成果统计**：名下资产、驾驶里程、果园收成与属性突破记录，可在【**统计 → 模组统计**】中完整阅览。
- **模块自定义**：目录右侧的复选框支持独立启用或停用子模块（调整模块开关后请先保存存档并重新加载）。
