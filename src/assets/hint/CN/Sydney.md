### 前置条件与路线选择

启用「悉尼拓展」并重载。学校、神殿、庄园分别有自己的许可。<span class="teal">认识悉尼、选择悉尼为恋人、取得宿舍邀请、取得庄园地址不会互相代替。</span>

| 路线       | 起点                   | 先准备什么                               |
| ---------- | ---------------------- | ---------------------------------------- |
| 科学课换班 | 科学课与午餐           | 已熟识悉尼，实际上过科学课并听到换班提示 |
| 神殿宿舍   | 神殿宿舍悉尼工作处     | PC 修士身份、宿舍进入资格、压力未满      |
| 贞操带谈话 | 原版堕落房间后续、神殿 | 悉尼恋爱关系与相应原版进度               |
| 西里斯庄园 | 成人用品店西里斯谈话   | 满足下文任一邀请路线                     |

### 科学课：如何解锁、在哪里、怎么做

1. 在学校推进与悉尼的原版关系，正常参加科学课。
2. 达到可以谈换班的关系阶段后，科学课会给西里斯的提示。
3. 在食堂与悉尼共进午餐，询问科学课换班并接受。
4. 从后续科学课查看同桌和课内互动。悉尼是否出现仍读取当天课程与人物日程，不会永远坐在教室。

整理笔记可帮助课堂学习，交谈有好感与压力变化。部分调侃选择另受悉尼堕落、欲望和 PC 态度等级限制，接受换班不等于全部选项同时开放。

礼顿接管课堂检查时，西里斯会叫悉尼帮忙搬书，一起离开。西里斯的解剖示范中，悉尼会按当前状态作出反应。回到座位后可借阅笔记，学习与好感收益<span class="blue">每日一次</span>。

<span class="teal">只有好感进展却没听过课堂提示时，先上科学课，再回午餐谈话。</span>考试、缺课或人物不在场时不能把普通午餐当成补发所有课堂事件的入口。

### 神殿宿舍：邀请与日常

**解锁步骤**：取得修士身份与宿舍资格，在悉尼正在宿舍工作、PC 压力未满时，当面问能否来床铺旁坐坐。获邀请后才出现床铺入口。其他阶段的神殿身份不自动代替首次邀请要求。

| 活动         | 怎么使用                               | 效果与限制                                             |
| ------------ | -------------------------------------- | ------------------------------------------------------ |
| 阅读         | 在床铺处选阅读，约 10 分钟             | 有历史相关对话和收益，每日有限，能力达标会出现额外内容 |
| 谈话         | 悉尼在场时选择当日话题                 | 推进日常关系，已聊过的内容受当日限制                   |
| 衣柜与上床   | 使用宿舍自己的衣柜、睡衣或脱衣入口     | 私人物品与在场状态仍检查，不会召回外出的悉尼           |
| 转化部位互动 | 好感达标且 PC 有可见的完整动物转化部位 | 按当日次数限制开放，隐藏或尚未形成的部位没有对应选项   |
| 留宿与夜醒   | 在可使用床铺时选睡眠时长               | 读取悉尼是否休息、是否在场和当前事件，非固定每天触发   |

恋人亲密内容还要在态度页选择悉尼，当前神殿任务、受罚和日程优先。宿舍邀请不是全时段的相处保证。

### 贞操带：前置与结果

在原版堕落房间剧情后，悉尼为恋人、当前未佩戴贞操带、没有神殿评估事件且 PC 未许诺给悉尼时，到神殿询问重新佩戴。

- 纯洁状态的悉尼可以自愿跟你找约旦。
- 堕落状态会拒绝，动摇状态有不同答复。
- 拒绝不会暗中改变贞操带，也不能用反复点击把拒绝当成已同意。

### 西里斯庄园：两条邀请路线

| 路线         | 条件                                                     | 操作                       |
| ------------ | -------------------------------------------------------- | -------------------------- |
| 悉尼恋人路线 | 已是悉尼恋人，并认识其家长                               | 在成人用品店当面询问西里斯 |
| 店员路线     | 已在成人用品店任店员，与西里斯充分熟识，当前不是悉尼恋人 | 在店内询问西里斯庄园       |

获得邀请后，从 **多瑙河街 → 西里斯庄园**进入，PC 不能裸露。庄园不是房产柜台可购买的那座多瑙河街宅邸。

**约悉尼晚上回家**：17:00 至 21:00 前在神殿宿舍商量，悉尼必须正在宿舍工作，当天没有相关受罚，PC 压力未满且不裸露。约定后从 21:00 起前往庄园。

### 庄园各处有什么用

| 地点     | 内容                     | 限制                                                       |
| -------- | ------------------------ | ---------------------------------------------------------- |
| 大厅     | 查看谁在家、日常谈话     | 西里斯与悉尼各有日程，不会固定同时出现                     |
| 书房     | 阅读与课后讲解           | 风纪委员／会长可每天准备一次，科学能力达标才有修正讲义分支 |
| 厨房     | 家庭日常与生活对话       | 读取当前在场人物与进度                                     |
| 花园     | 庄园户外内容             | 不等于 PC 已取得产权或自己的种植地                         |
| 悉尼房间 | 床、衣柜、镜子和夜间互动 | 仍看悉尼在场、许可与恋人条件                               |

课后讲解联动「模拟人生」的学生声望与教职工信任。镜子联动「原版增强」诡异镜面，住所许可不代替镜面特质。

### 节庆、效果与排查

万圣节与圣诞节内容接在原版相应日期事件后。跨人物万圣夜成就要求同一年完成相关拜访，不是随时进庄园一次就算完成。

本模块增加课堂、宿舍与家庭生活，不取消悉尼神殿职责、监禁、节庆或受罚。入口缺失先查 **哪条许可 → 人物地点 → 原版阶段 → 恋人选择 → 时段、压力、裸露 → 每日次数**。
