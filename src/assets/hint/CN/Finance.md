## 从这里开始

启用「金融系统」并重载。金融中心从商业街进入，家具从家具店的**入口页**选择自住房。人物同住另需对应恋人关系。

| 想做什么       | 去哪里                        | 先准备什么                                         |
| -------------- | ----------------------------- | -------------------------------------------------- |
| 现金改用卡付款 | 金融中心的银行柜台            | 开户、办卡，借记卡存款或信用卡可用额度             |
| 买房           | 金融中心的房产柜台            | 银行存款，或符合条件的首付、手续费与一期周供准备金 |
| 配置自住房     | 家具店入口 → 为自住房选购家具 | 已购且能使用的住宅，按目标住宅选分类               |
| 邀请恋人同住   | 对方当前所在的原版地点        | 已列为恋人、可用床位、房源容量、未出租和未冻结     |
| 查看账单       | 游戏日志的财务部分            | 查看账户、持仓、房产总账、还款日期与逾期状态       |

<span class="teal">购房、贷款与定期账单有各自的银行结算规则，不等同于商店里的当前付款方式。</span>

## 选择你的经营路线

| 目标               | 接下来查看的章节 | 起步顺序                                               |
| ------------------ | ---------------- | ------------------------------------------------------ |
| 存款、用卡和交易   | 银行与投资       | 开户 → 办卡或证券账户 → 存入资金                       |
| 开公司、经营工厂   | 企业与治理       | 企业登记 → 办公室和工厂 → 签约、生产、交付、收款       |
| 进入艾弗里的董事会 | 企业与治理       | 履约三笔订单 → 已交割持股20% → 通过会议取得席位 → 控股 |
| 买房与邀请同住     | 住宅与生活       | 选房 → 支付与布置 → 在恋人所在地邀请                   |

账户与任务的当前情况看**日志**，累计履约与实收看**统计**。开放的作弊控件位于原版**作弊 → 枯木逢春**，资源调整不会替你办理任职、借款或结案手续。

## 时间推进与账期

向较晚日期跳转时，房产、公司、工厂、银行与雇工账务会沿用各自的账期补算，果园和罗宾饮品店投资也会按原有联动入账。跨过多天时，先处理对应日期的经营收入，再处理当天到期的债务。车辆保养费按已跨过的整周补计。

重复结算同一日期不会重复领款或扣费。把日期调回过去不会撤销已经入账的收支，再次前往已结算的日期也不会重新获得收益。

## 与街头玩法联动

启用街头模块后，金融中心的银行也是豪劫目标，工厂的包装产线可协助准备用品。银行遇袭会暂停柜台业务两天，现有贷款与日常账单仍需处理。路线与选择见**街头生活**章节。
