### 选择起步路线

马、鲸与渡鸦各有六个阶段，在角色页查看成长，在镜子中选择部位显示。阶段成长与外观开关分开，隐藏部位不会清空积累。

| 转化 | 从哪里开始                                                                                                                     | 后续积累                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| 马   | 到雷米骑术学校上课，每节<span class="gold">£25</span>。课堂中遇到树林果实时，摘下并吃掉，增加5点，果实有药物影响，事件随机出现 | 已开始马化后，农场成功追上跑开的马并刷毛增加1点，荒原成功骑行也有增长机会        |
| 鲸   | 海滩游向岩石，爬上后进入岩石水池，选择「在水池里漂浮」，10分钟增加1点                                                          | 漂浮可重复，正常游泳与完成水下动作也有增长机会                                   |
| 渡鸦 | 白天或黄昏在森林主动循声寻找（75%成功），或到老教堂墓地寻找（必定成功），首次增加5点                                           | 再次寻找鸟群后，喂食每天一次增加2点，模仿叫声、梳理已长出的覆羽各每天一次增加1点 |

主动寻找花15分钟，森林与老教堂墓地共用每天一次的寻找机会，失败不增长，也不消耗水果。森林安全事件中的随机鸟群仍可跟随或喂食，出现权重由0.33提高到1。正常事件池中约有27.3%的机会遇见鸟群（此前约11.0%），长发与节日事件会改变比例，这不是每次行走的总概率。

首次认识鸟群后，寻找它们只需5分钟，不再判定概率，在两个地点喂食、模仿叫声与梳羽均共用每日次数。喂食消耗一份黑莓、草莓或苹果，花5分钟，模仿叫声与梳羽各10分钟。跟随随机鸟群花15分钟，并进入更深的森林。夜间、森林追猎、血月、濒临昏厥或已排定下一场景时不能停留。

发现原版孤儿院阁楼并请瑞沃安装厨房后，也可以在那里煮白米饭积累鲸化：一碗10分钟、增加1点，三碗30分钟、增加3点。安装厨房需<span class="gold">£10,000</span>和3小时，之后每天至少补足三份米。

### 阶段带来的能力

| 转化 | 阶段与效果                                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 马   | 第2阶段「蹄足」使踢击反抗效果达到三倍，第3阶段「汗血」将偏离正常体温的变化减半，第4阶段长马耳，第6阶段长马尾并减缓疲劳积累          |
| 鲸   | 第2阶段「深潜」减少75%水下耗氧，第3阶段「鳍肢」提高10%有效游泳技能，第4阶段长耳鳍，第6阶段长鲸尾，水下动作耗时减半，最低1秒         |
| 渡鸦 | 第2阶段获得「锐目」，有效诡术提高5%，第4阶段长覆羽与尾羽，「玄翎」减轻15%击打带来的新疼痛，第6阶段长完整羽翼，遭遇战言语效果提高25% |

「玄翎」不消除已有疼痛，「锐目」与其他动物转化的同名特质不重复叠加。马类相关遭遇也可积累马化，是可选途径。

### 保留转化与混合外观

购物中心二楼服装店出售保形饰品，**要实际穿戴**才阻止对应转化自然衰退和受到其他动物转化压制：

- 马：头饰**鬃毛缎带**，或颈饰**金色胡萝卜吊坠**。
- 鲸：头饰**珍珠贝壳发夹**。
- 渡鸦：颈饰**鸦羽项链**，<span class="gold">£45</span>。

想同时保留马与鲸，可用马的颈饰把头饰位置留给鲸。马尾与恶魔尾、渡鸦羽翼与神性羽翼同时形成后，可在镜子的混合转化选项中选择外观，这些选择不增加成长，也不决定下列能力是否生效。

### 两种融合能力

- **不祥谶言**：完整渡鸦转化，加上已能使用「讥讽」的堕天使阶段。每场遭遇可讥讽两次，鸦化加成后的自控恢复和创伤缓解翻倍，每次还减轻15%当前疼痛。无法正常说话时仍受原动作限制。
- **狐火**：同时完整天使与狐转化。成功「放逐」一条触手时，狐火可波及另一条存活触手，造成主目标实际伤害的四分之一，不再耗放逐次数。没有第二条目标时只有原本的放逐效果。

转化衰退后，依赖阶段的能力会暂时失效。继续照对应路线积累即可恢复，完成三种转化分别获得「踏风逐野」「鲸跃沧溟」「玄翎渡夜」。
