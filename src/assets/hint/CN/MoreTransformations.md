# 动物转化、黯羽神社与寒月港湾

## 动物转化

马、鲸、渡鸦各有六个阶段，进度在角色属性页查看，外观在镜子里选择。隐藏部位不会失去相应能力。转化称号与能力列在**特质 → 转化特质**。

| 转化 | 开始与成长                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------------- |
| 马   | 雷米骑术课£25一节，林间果实事件中食用果实可得5点，也会受到药物影响。开始马化后，追回受惊马匹并梳毛可得1点，荒原骑乘也有成长机会。 |
| 鲸   | 海滩远处礁石的岩石水池中，漂浮10分钟得1点。阁楼白米饭也能开启鲸化。已有鲸化点数后，游泳与潜水继续积累，满游泳技能也有效。         |
| 渡鸦 | 白天或傍晚寻找鸦群，初见得5点。之后每天喂一份浆果或苹果得2点，模仿鸣叫每天得1点，长出覆羽后梳羽也得1点。                          |

**找鸦群**：森林入口在深度10–14的老教堂墓地选项上方，成功率75%；白天的墓地，以及公园长椅旁07:00–10:00、16:00–19:00的鸦群必定能找到。初次寻找15分钟，各地点共用每天一次机会；认识后再找只需5分钟。投喂5分钟，鸣叫和梳羽各10分钟，每项每天一次。森林仍可能偶遇鸦群，跟随会花15分钟并深入森林。夜晚、血月、追猎或即将昏倒时不能停留。公园长椅平时也能休息15分钟，可能遇到原版公园事件。

鲸化的三种水中活动各有每日2点上限：漂浮每10分钟1点，游泳每次原版技能增长1点，潜水每累计完成1分钟水下行动1点。等候不算潜水。阁楼厨房由瑞沃安装，费用£10,000、用时3小时，此后每天补充至少三份米。煮一碗米饭10分钟、1点，三碗30分钟、3点。

在购物中心二楼买到并**戴上**保形饰品，可阻止对应转化衰退和被其他动物转化压制：马用鬃毛缎带或金色胡萝卜吊坠，鲸用珍珠贝壳发夹，渡鸦用£45的鸦羽项链。马与鲸共存时，可把头饰位留给鲸，马用颈饰。马尾与恶魔尾、渡鸦与神性羽翼同时形成后，可在镜子里选融合外观。转化衰退到所需阶段以下时，相应能力暂停。

- **不祥谶言**：完整渡鸦形态＋堕天使的「讥讽」阶段。每场讥讽可用两次，自控恢复和创伤缓解翻倍，每次再减轻当前疼痛的15%。
- **狐火**：完整天使＋完整狐狸形态。成功放逐后，另一条存活触手受到主目标实际伤害的四分之一，不另耗次数。

## 黯羽神社

在**三个不同日子**喂过鸦群后，趁鸟还在时收取信件；错过可下次再取。把信交给森林商店的格威岚，取得回信与指路，也可收下送到衣柜的鸦羽项链。森林深度20–40会出现神社小路，往返各15分钟，返回原深度，血月或追猎时关闭。

首次到访会认识19岁的月羽，头衔按人物设定显示神官、巫女或侍者。此后可在态度页选为恋人。信件、路线与待办见日志，累计奉纳和帮忙记录见模组统计，关系数值见人物关系页。

**任性**初始10、范围0–100，影响说话和提出要求的方式：30以下较拘谨，30–69会说出自己的偏好，70以上更爱撒娇、留人或挑喜欢的茶点。普通聊天、帮忙、喝茶与亲吻不会自行增加任性。拿纸鸦逗月羽加1，客气地只谈神社事务减2。

好感10后，「看看月羽有什么小要求」会在陪伴和草莓之间轮换：多留5分钟或送一份草莓，好感和任性各+2；婉拒不扣好感、任性−2。也可答应下次带草莓，任性+1，期限为**次日18:00前**，交付需留5分钟。按时交好感+2，逾期交+1，均任性−1；提前取消不扣好感，逾期道歉好感−1，均任性−2。逾期不会每天反复扣分。

好感满100后，仍从小要求入口进入表白，可接受、再考虑或保持朋友关系。接受时有空位才会把月羽加入恋人，已有恋人不会被替换。恋人好感20可调情，5分钟、好感+1、压力−2、性欲+3，每天一次。好感50后可在廊下提出单独待会儿，10分钟、压力−4、好感+2，每天一次；可以亲近，也可以只说话，后续仍由你选择。

### 祈愿、绘马与果树

庭院和池塘夜里也能到访。静坐祈愿15分钟，压力−6、创伤−1；池边休息10分钟，压力−3、疲劳−6，各每天一次。祈愿可奉纳£5，与免费祈愿共用次数。累计奉纳的改善会保留：

| 累计奉纳 | 改善与额外收益                        |
| -------- | ------------------------------------- |
| £25      | 换坐垫，祈愿压力再减3。               |

手水舍洗手2分钟，只清洁双手。绘马每天可写一块，£1、5分钟、压力−2。平安愿需过了当天再沿森林参道平安返回；学业愿需认真上完一堂原版课程，满成绩也算；丰收愿需亲手采下神社熟果。达成后还愿5分钟、压力−3，每个愿一次。可把心愿告诉在场的月羽，好感+1，之后交谈会提起。写满**7个不同日子**得**心有所寄**，每日祈愿额外创伤−1，不要求连续。

屋后是果园系统中的苹果树和李子树。好感10时，趁月羽在庭院或果园花10分钟查看，即可帮忙种植、浇水、施肥与采收。第一批果实需七天有水生长，成熟后可直接摘，也可在果园选「采摘」后点树。月羽每天会照料，缺席时停止。累计**3次实际采收**得**春晖**，有效护理+7%；按采收次数算，不按果子个数，换树保留进度。其他果园玩法见[果园](#deadwood-guide-Orchard)，心智恢复见[心智](#deadwood-guide-Psyche)。

### 月羽的小屋

从庭院绕到屋门，07:00–09:00、12:00–13:00、18:00–22:00可敲门，1分钟。好感30且已选为恋人后会受邀入内，维持恋人关系与30好感便可在月羽外出时自行休息，进出各1分钟。月羽醒着且有空时，可聊天或一起读书，10分钟，共用每天一次的压力−4、好感+1。

寝室只有一床宽褥子，月羽夜里在家时同睡，白天独自休息。平时20:00–20:30洗澡，雨中工作后改为18:00洗澡并换干衣；22:00–07:00穿睡衣。洗澡20分钟，清洁身体、压力−4、疲劳−3。浴室有人时可以等候或开门，恋人可留下同洗；性欲30且尚有当天亲密机会时，可继续亲近。未经许可闯入好感−2、任性+2，非恋人可道歉挽回1好感，每天只结算一次。

未获邀请时，月羽外出、睡觉或洗澡可尝试潜入，每天一次，5分钟。熟睡时诡术难度500，其他情况300。潜入不等于受邀，月羽醒来或回来会请你离开，也不能自行留宿或自由使用浴室。

## 寒月港湾与亡船

梅尔街小巷步行5分钟到港湾。平日可探索、游泳与潜水搜寻残骸，找到可交易的旧物，也可能得到原版铜罗盘或锈蚀弯刀。普通古董可重复取得并增加卖价，不重复增加馆藏。游泳、氧气和鲸化仍按原有规则。

血月21:00至次日06:00，亡船随海雾靠岸。探索可能遇到一至三名亡灵劫掠，也可能听见水下呼唤。可离开，以诡术或运动躲避，或进入战斗，躲避失败也会遭遇。普通攻击、天使放逐及神殿借来的短棍、鞭子都能伤害亡灵，放逐照常消耗次数。仍有意识的海盗可用一件旧物换£10，一次交易。天亮后雾与亡灵退去，物品和线索保留。

**泽菲尔的货物**：见过亡船、认识泽菲尔后，在船上或走私者酒吧询问港湾，可接找箱子的委托。报酬£80，正式船员£120；接下时可讲价，诡术难度400，正式船员300，成功加£40。血月夜在港湾水下搜寻，每次有三分之一机会找到。交货得报酬、兴趣+2，正式船员另得海盗尊重+2，此后白天有船员小事件。

**海上登船袭击**：在泽菲尔船上过夜可能遇到，血月更常见，两次至少隔3天，不打断抵岛等强制事件。血月敌人更强，迎战前有提示。

- 迎战使用正式战斗与装备武器，放逐和神殿武器也有效，同一件借用武器双手选择仍只攻击一次。
- 断绳检定诡术与体能；营救落水船员检定游泳与体能。成功可增加尊重和兴趣，失败有船员接应。
- 也可躲回船舱，交给船员应付。天亮亡灵退去。

战后可离开，或花5分钟向泽菲尔问怪船、在舱口歇息。交谈和休息各一次，可都选；休息压力−4、疲劳−3。交谈会引出港湾委托，接任务仍需另外答应。上述委托与船袭都不会直接晋升船员。

## 海岛藏金与亡灵诅咒

发现海岛海岸后继续探索可找到旧洞窟。入口火盆可点火把，移动与调查会耗火，黑暗更容易漏看危险。沿途记号可帮助返回，游泳、运动、诡术各有用处，也有无需技能的慢路。找到石箱后可走近路。

取金会受到亡灵诅咒：

- 免疫疼痛与冷热，性奋正增长减少75%。
- 睡眠疲劳恢复×0.5，每小时承受一次原版噩梦压力，不与已有噩梦叠加。
- 反抗伤害−50%，包括借用武器的近战挥击；喷雾和触手生命伤害另算，体能原值与挣脱不变。
- 罗宾饮品、神社茶点等模组情节中，品尝不再舒缓心情，陪伴仍有效；原版餐饮不变。晴朗月夜在海边或甲板上会显出骨骼。

旧笔记、刻字和温特鉴定提供线索。解除诅咒须把**全部原金币放回石箱**，送人不算归还，解咒后仍可再取。温特可鉴定、借展，原币需领回，博物馆保留翻模，考察酬金只发一次。

告诉泽菲尔洞窟的事，可安排约一周的原版航程，到达后共同乘小艇上岸，回船后再选择返岸。未查明警告就分金，船长也会受诅咒，还可能把金币分给帮忙的船员。归还时须召回这些金币，可凭证据、船员身份、关系或补偿谈判。

**金币任务与海上亡船袭击独立推进**。日志追踪金币去向与下一条线索，模组统计保留探索和归还记录。
