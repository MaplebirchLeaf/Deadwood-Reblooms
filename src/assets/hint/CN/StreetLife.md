## 从哪里开始

启用**街头生活**并重载。街头口碑覆盖整个小镇，走私者酒馆只是据点之一，警方犯罪记录仍另行计算。先与丰收街酒馆的兰德里交谈，或到警察局认识警探格兰特。

| 想做什么               | 去哪里                                | 先准备什么                                                   |
| ---------------------- | ------------------------------------- | ------------------------------------------------------------ |
| 接运输、找货和销赃委托 | 丰收街酒馆 → 兰德里                   | 能正常行动，手头没有另一份货运委托                           |
| 买武器与弹药           | 已发现的走私者酒馆 → 武器店           | 可用付款资金，支持金融模块的商户付款方式，武器从手持目录购买 |
| 接警方悬赏             | 警察局，08:00–18:00                   | 与格兰特谈好合作，警方记录未妨碍领赏                         |
| 请米奇核对消息         | 走私者酒馆，09:00–18:00               | 已认识原版的米奇，能正常交谈                                 |
| 筹划银行豪劫           | 兰德里 → 走私者酒馆私下会面           | 金融模块、足够口碑，以及兰德里和伦恩的信任                   |
| 参加公路赛             | 丰收街外的第一段农场公路，20:00–04:00 | 交通模块、停在当地的汽车、驾驶资格、足够燃油与现金           |

当前任务、货物位置与待办事项看**日志**，实际领款、货损和已结案的行动结果看**统计**。随时查看日志不会重新抽取委托，也不会替你交货或领钱。

## 农场公路赛

夜间到丰收街外的第一段公路，可以打听比赛、旁观，或开自己的汽车参赛。赛事沿公路前往农田，分入门组与进阶组，普通汽车也能参加，摩托车与自行车暂不在这一组比赛中。雪天停赛，雨天更容易失去抓地力。正在处理道路遭遇时，先解决眼前的事。

报名之前看清费用、奖金与车辆状态。汽车要实际停在起点附近，不能从车库远程调来，载客、送货等未完的工作也要先处理。比赛分别考验驾驶技术、车辆性能与临场判断，买到更贵的车并不保证获胜。

入门组报名费为 <span class="gold">£25</span>，前三名奖金依次为 <span class="gold">£90／£35／£10</span>，进阶组要求驾驶熟练度达到300，报名费为 <span class="gold">£100</span>，前三名奖金为 <span class="gold">£300／£150／£50</span>。报名用时2分钟，正常跑完全程另需21分钟，参赛车况至少为45%，还需备足全程燃油。

每段选择稳健驾驶、提速或冒险提速。稳健更容易保住车况，冒险有机会抢位置，也可能失误，车流、弯道和雨水都会影响判断。同一组每晚只能报名一次，退赛也计入，凌晨四点换夜，跨过午夜不会立刻刷新。

完赛领取名次对应的奖金，并留下驾驶经验与比赛记录。报名费、燃油和车损都是真实消耗，退赛不会退还报名费，也不会把人车送回起点。非法竞速被辨认出来时会留下原版犯罪记录，警方合作关系不会替你免除后果。**日志**保留正在进行的赛程与最近结果，**统计**记录比赛次数、冠军、报名支出与奖金实收。

**老练车手**：驾驶熟练度达到600并累计完赛10次后，驾驶汽车的基础车况损耗减少**10%**，普通行驶与公路赛都生效。激烈驾驶与事故造成的额外损耗照常，自行车和摩托车不享受这项收益。日志会显示取得特质的进度。

**先到一步**：首次完整跑完进阶组并取得冠军。这项成就记录比赛成绩，不额外发放奖金。

## 走私者酒馆

沿原版地下路线发现酒馆后，才会出现新的日常菜单。可以喝茶、休息、听消息、帮忙整理，也可以玩现金二十一点或德州扑克。酒馆用现金结算，康努达塔斯街赌馆的筹码留在赌馆。

茶每杯 <span class="gold">£2</span>，用时5分钟，每天最多三杯，休息15分钟，每小时可安排一次，听消息每天一次。整理工作每天一次，用时15分钟，完成后得 <span class="gold">£4</span>。原版任务或人物正在占用酒馆时，先处理眼前的事。

## 武器与手持物品

武器店沿用服装店的购买、耐久和装备操作，目录只出售手持武器。现有小刀、电击器、撬棍、砍刀、手枪、霰弹枪、冲锋枪与步枪。可在同一手持物品类别中管理双持，具有相同功能标签的物品不能同时装备。

武器动作出现在**遭人袭击的人类战斗**中，需要相应手臂可用，目标尚未被击败。拿着武器不等于可以在所有遭遇中使用。

| 枪械   | 一次行动耗弹 | 弹药       |
| ------ | ------------ | ---------- |
| 手枪   | 1发          | 手枪弹药   |
| 冲锋枪 | 3发          | 手枪弹药   |
| 步枪   | 2发          | 步枪弹药   |
| 霰弹枪 | 1发          | 霰弹枪弹药 |

余弹不足一组时仍可开火，按实际发数结算。枪械伤害包含固定值和目标最大生命的比例，射击熟练度提高效果，疼痛会削弱效果，有效系数为60%–100%。开火会增加原版袭击犯罪记录，受伤目标移交时还需医疗处理。

手持枪械时，属性页的武器栏目会显示现有射击练习记录与当前伤害系数，已计入疼痛影响。副手持枪也会显示。

## 兰德里的委托

日常委托优先提供三份合法工作和一份非法工作，不符合口碑、地点或模块条件时，可见数量会减少。医院补货、图书、食品、修车零件、制服与文件运输都可能出现，非法委托还包括赃物和毒品运输。详情会标明来路、目的地、报酬、截止时间和风险，先读清楚再接。

1. 接下委托，去指定地点取货。若货物短缺、价款争议或单据有问题，可以检查、等候或交涉。
2. 徒步携带，或装入附近有足够货位的载具。装车后，货物跟着那辆车走，人到目的地而车没到，不能直接交货。
3. 在收货地点及营业时间内卸货、交付，再按约定返回领款。仅接单或交货不计为实收收入。
4. 无法继续时可以退货或取消，按委托提示承担相应后果。非法货物可能招来搜查、扣押或冲突，普通运输也可能出错。

迟交报酬通常降为75%，未解决的短货或价格争议也会影响结算，两个折扣可能叠加。车辆失窃、货物扣押和超过宽限时间，都会影响能否履约。

## 警方悬赏与双向追缉

与格兰特合作后，告示板按信任和开放地点提供案件。每份线索有效72小时，先到目击地点调查，再核对目标身份。可以劝说、追赶，或在冲突中进入原版战斗。汽车需要停在附近，有座位、油量和驾驶资格，不能凭空把目标送到警局。

完成移交后，回警局在08:00–18:00领取赏金。目标受枪伤时，先按现场提示处理伤情。犯罪记录会妨碍接案或领款，与警方合作不会自动销掉记录。

核对身份后，如果不想亲自抓捕，也可以在08:00–18:00到悬赏柜台把可靠线索交给在岗的格兰特。警方接手这次追缉，支付基础赏金的**20%**，信任增加1点，本次委托随之结束。线索费不计抓捕完成或类型进度，不享受赏金猎人奖金，不能再领取同一委托的抓捕报酬。

**赏金猎人**要求当前12类委托每类都实际领款至少一次。告示板和日志显示已完成类型与尚缺名称，重复同一类不能补齐其他类型。补齐最后一类的那单仍按原价支付，之后保持与格兰特合作时，基础赏金增加**15%**。首次核实、移交并领款还可获得**收网**成就。

你可以接兰德里的工作，也可以追缉犯罪目标，但双方并非同盟。犯罪记录严重时，其他赏金猎人也可能在街头追捕你，谈判、逃跑、驾车或反抗各有自己的条件与后果。

## 贝利与米奇

贝利的差事、扣货和威胁可与工厂经营、原有房租关系联动。可以在原版办公室或公寓找到相应入口，是否能谈判取决于口才、经济地位或已取得的独立地位。交钱、拒绝、求助或反抗，按当时选项处理，不会仅凭街头口碑免除旧债。

米奇可以帮你检查消息、分工和风险，仍保留原版名声委托。不要把两份相同传闻当成两个可靠来源。米奇不会自动加入外出行动，也不会替你同意警探或兰德里的要求。

## 银行豪劫

目标是**金融中心银行**。街头口碑至少50，认识兰德里与伦恩，兰德里需要充分信任你，伦恩好感至少20。原版黑箱与销赃成绩也能证明你在兰德里那里的资历。先约私下会面，再沿原版路线去走私者酒馆，在09:00–18:00继续筹备。

1. 与兰德里、伦恩商量计划，选择安静行事或公开强攻。
2. 核对银行信息、准备用品、进行演练。口才、数学、科学、家务、诡术与身体状态影响准备质量，有包装产线的正常经营工厂还可协助备货。
3. 面谈并雇用一名侦察者和一名搬运者。预付款与事后分成分别计算，中途撤回计划不退已经支付的报酬。队员的能力、伤势与去留都会影响行动。
4. 检查筹备、人员与选用的车辆，再开始行动。到场后仍可根据情况放弃、少拿钱或改变撤离方式。压力、疲劳、疼痛、醉酒和药物影响会降低表现。
5. 撤离后完成分账，才算结案。总赃款、PC分成与筹备开销不同，统计中的分到账款不等于净利润。

可以在筹备中联系格兰特，选择举报或协助抓捕，也可以改变自己向谁提供消息。每次选择都会影响相关人物的信任与后续合作，不能把两边的互相冲突要求同时算作完成。

银行遇袭后，柜台暂停接待两天，账户和贷款不会因此被取消。原版警方仍会追究犯罪。安静路线成功撤离、实际分账，而且全程未报警或被认出，才获得**悄然无声**，中途只潜入成功不算。

筹备保留各动作原有耗时：柜台核对20分钟，用品整理20–30分钟，排演30分钟，介绍人选15分钟，议价和聘用各5分钟。剩余营业时间不足时会直接说明原因，已经开始却被打断，会显示实际耗时，未完成的安排不收费或增长技能。所有安排都需要在收店前完成。

成功分账之后，还自由且能够工作的原班雇员会在走私者酒馆介绍普通订单：侦察员的仓储耗材单基础报酬<span class="gold">£120</span>，搬运员的港口配送单基础报酬<span class="gold">£160</span>。你仍需要沿实际路线取货、运送和取得签收凭据，再回丰收街找兰德里领款。

合作人的熟练度让总报价增加0–20%，合作人分得25%，你领取余下75%，报价在接单时锁定。每名合作人每天介绍一单，接下后占用当天名额，取消也不会退回。迟到或货物争议照常减少双方实领。付清一次成功委托后，合作人对应角色的熟练度增加10，上限1000。这些新收入不会清除银行豪劫留下的犯罪记录。
