## 从哪里开始

启用**街头生活**并重载。街头口碑覆盖整个小镇，走私者酒馆只是据点之一，警方犯罪记录仍另行计算。先与丰收街酒馆的兰德里交谈，或到警察局认识警探格兰特。

| 想做什么               | 去哪里                                | 先准备什么                                                   |
| ---------------------- | ------------------------------------- | ------------------------------------------------------------ |
| 接运输、找货和销赃委托 | 丰收街酒馆 → 兰德里                   | 能正常行动，手头没有另一份货运委托                           |
| 买武器与弹药           | 已发现的走私者酒馆 → 武器店           | 可用付款资金，支持金融模块的商户付款方式，武器从手持目录购买 |
| 接警方悬赏             | 警察局，08:00–18:00                   | 与格兰特谈好合作，警方记录未妨碍领赏                         |
| 请米奇核对消息         | 走私者酒馆，09:00–18:00               | 已认识原版的米奇，能正常交谈                                 |
| 找同伙、一起接小买卖   | 走私者酒馆，09:00–18:00 → 手头的差事  | 街头口碑20，兰德里愿意接洽，并有一些交货或销赃资历           |
| 筹划银行豪劫           | 兰德里 → 走私者酒馆私下会面           | 三条前置都已结清、金融模块、口碑70，以及兰德里和伦恩的信任。新约定另有两桩先行大案 |
| 参加公路赛             | 丰收街外的第一段农场公路，20:00–04:00 | 交通模块、停在当地的汽车、驾驶资格、足够燃油与现金           |

当前任务、货物位置与待办事项看**日志**，实际领款、货损和结案结果看**统计**。

## 农场公路赛

夜间到丰收街外的第一段公路，可以打听比赛、旁观，或开自己的汽车参赛。赛事沿公路前往农田，分入门组与进阶组，普通汽车也能参加，摩托车与自行车暂不在这一组比赛中。雪天停赛，雨天更容易失去抓地力。正在处理道路遭遇时，先解决眼前的事。

报名之前看清费用、奖金与车辆状态。先在汽车的出行菜单中选择“出镇公路”，开到起点后再走近赛车，停在丰收街或车库里的车不能远程参赛。载客、送货等未完的工作也要先处理。比赛分别考验驾驶技术、车辆性能与临场判断，买到更贵的车并不保证获胜。

入门组报名费为 <span class="gold">£25</span>，前三名奖金依次为 <span class="gold">£90／£35／£10</span>，进阶组要求驾驶熟练度达到300，报名费为 <span class="gold">£100</span>，前三名奖金为 <span class="gold">£300／£150／£50</span>。报名用时2分钟，正常跑完全程另需21分钟，参赛车况至少为45%，还需备足全程燃油。

每段选择稳健驾驶、提速或冒险提速。稳健更容易保住车况，冒险有机会抢位置，也可能失误，车流、弯道和雨水都会影响判断。同一组每晚只能报名一次，退赛也计入，凌晨四点换夜，跨过午夜不会立刻刷新。

完赛领取名次对应的奖金，并留下驾驶经验与比赛记录。报名费、燃油和车损都是真实消耗，退赛不会退还报名费，也不会把人车送回起点。非法竞速被辨认出来时会留下原版犯罪记录，警方合作关系不会替你免除后果。**日志**保留正在进行的赛程与最近结果，**统计**记录比赛次数、冠军、报名支出与奖金实收。

**老练车手**：驾驶熟练度达到600并累计完赛10次后，驾驶汽车的基础车况损耗减少**10%**，普通行驶与公路赛都生效。激烈驾驶与事故造成的额外损耗照常，自行车和摩托车不享受这项收益。日志会显示取得特质的进度。

**先到一步**：首次完整跑完进阶组并取得冠军。这项成就记录比赛成绩，不额外发放奖金。

## 走私者酒馆

沿原版地下路线发现酒馆后，才会出现新的日常菜单。可以喝茶、休息、听消息、帮忙整理，也可以玩现金二十一点或德州扑克。酒馆用现金结算，康努达塔斯街赌馆的筹码留在赌馆。

茶每杯 <span class="gold">£2</span>，用时5分钟，每天最多三杯，休息15分钟，每小时可安排一次，听消息每天一次。整理工作每天一次，用时15分钟，完成后得 <span class="gold">£4</span>。原版任务或人物正在占用酒馆时，先处理眼前的事。

## 武器与手持物品

武器店沿用服装店的购买、耐久和装备操作，目录只出售手持武器。现有小刀、电击器、撬棍、砍刀、手枪、霰弹枪、冲锋枪与步枪。可在同一手持物品类别中管理双持，具有相同功能标签的物品不能同时装备。

武器动作出现在**遭人袭击的人类战斗**中，需要相应手臂可用，目标尚未被击败。拿着武器不等于可以在所有遭遇中使用。

| 枪械   | 一次行动耗弹 | 弹药       |
| ------ | ------------ | ---------- |
| 手枪   | 1发          | 手枪弹药   |
| 冲锋枪 | 3发          | 手枪弹药   |
| 步枪   | 2发          | 步枪弹药   |
| 霰弹枪 | 1发          | 霰弹枪弹药 |

余弹不足一组时仍可开火，按实际发数结算。枪械伤害包含固定值和目标最大生命的比例，射击熟练度提高效果，疼痛会削弱效果，有效系数为60%–100%。开火会增加原版袭击犯罪记录，受伤目标移交时还需医疗处理。

手持枪械时，属性页的武器栏目会显示现有射击练习记录与当前伤害系数，已计入疼痛影响。副手持枪也会显示。

## 兰德里的委托

日常委托优先提供三份合法工作和一份非法工作，不符合口碑、地点或模块条件时，可见数量会减少。医院补货、图书、食品、修车零件、制服与文件运输都可能出现，非法委托还包括赃物和毒品运输。详情会标明来路、目的地、报酬、截止时间和风险，先读清楚再接。

1. 接下委托，去指定地点取货。若货物短缺、价款争议或单据有问题，可以检查、等候或交涉。
2. 徒步携带，或装入附近有足够货位的载具。装车后，货物跟着那辆车走，人到目的地而车没到，不能直接交货。
3. 在收货地点及营业时间内卸货、交付，再按约定返回领款。仅接单或交货不计为实收收入。
4. 无法继续时可以退货或取消，按委托提示承担相应后果。非法货物可能招来搜查、扣押或冲突，普通运输也可能出错。

送酒水上楼、送酒馆工作服、咖啡馆补货和码头工具这几类委托，有四分之一机会遇上纠缠：堵楼梯的客人、拦路搭话的人，或冒收搬运费的陌生人。可以留在工作人员看得见的地方等候10分钟，诡术达到400时也能花5分钟跟着人群绕开。仍可离开或决定退货。解围后照常交接，不额外扣报酬，耽误到超时则沿用迟交规则。每单的问题在接单时确定，重进页面不会换一批人或重复结算。

迟交报酬通常降为75%，未解决的短货或价格争议也会影响结算，两个折扣可能叠加。车辆失窃、货物扣押和超过宽限时间，都会影响能否履约。

## 三件小买卖

发现走私者酒馆、认识兰德里，街头口碑达到20后，可以在09:00–18:00打听人手与差事。兰德里需要愿意与你接洽：好感至少20、原版黑箱任务累计25次，或已有<span class="gold">£1,000</span>销赃实收。此外，完成并领款两份街头委托、完成三次原版黑箱任务、销赃实收达到<span class="gold">£1,000</span>，满足其中一项即可。已经与兰德里闹翻时，旧成绩也不能让他回心转意。

先请兰德里介绍人手，安排一名侦察员与一名搬运员，再从酒馆的**看看同伙与手头的差事**里接洽。三桩事依次展开，途中需要自己走到对应地点，日志会记下下一站。酒馆、码头、工业区巷道与海风咖啡馆的接洽时间为09:00–18:00，每一步都要留够时间做完。

| 约定           | 去哪里                                        | 做什么                                   |
| -------------- | --------------------------------------------- | ---------------------------------------- |
| **少了一箱货** | 酒馆 → 码头 → 工业区巷道 → 酒馆               | 查清单据与封签，处理交货争议，再回去结账 |
| **该带走什么** | 酒馆 → 工业区巷道 → 码头 → 酒馆               | 与伦恩一起行动，在货物与同伙之间作出取舍 |
| **风声与底细** | 酒馆 → 海风咖啡馆 → 工业区巷道或警察局 → 酒馆 | 分清亲眼所见与转述，再核对另一处来源     |

结清兰德里的交货后，认识伦恩且伦恩好感达到20，才会谈起第二桩事。如果原版里已经与伦恩做过那次豪宅买卖，这份共同经验也会派上用场。

伦恩的事有了交代，就能开始核对消息。已经认识米奇，又方便在酒馆碰面的话，可以请米奇帮忙。**还没认识米奇，也能自己查下去**。已经认识格兰特、谈好合作，且他在警局值勤时，也可向他问起旧案。不方便见警探，就去巷道寻找独立来源。核对旧案不会替你答应另一桩买卖，更不会免去自己的罪证。

这三桩事不要求次次顺利。折损交货、留下货物或保留疑点，都可以把事情做完、结清。报酬与之后的安排会记住你的取舍。回去说明结果，才算有了交代，不能只接下约定就去开启银行行动。

若需要换人，先回酒馆，在手头差事里花5分钟选择**暂缓约定，重新商量人手**。即使雇员暂时来不了，也能先停一停。走到哪一步、查明的情况、先前的选择与支出都会保留。调整好人手，两名雇员都能参加后，再花5分钟选择**重新约好人手，接着办事**，从没做完的地方继续。先前的判定不会重来，已经给过的报酬与经验也不会再领。暂停不算完成。已经结清的约定则不会重开。

## 同伙与日常合作

兰德里介绍的三个人会一直保留。姓名、外貌、侦察与搬运的初值、各自的成长率，在首次介绍后就定下来了，反复查看不会换一批人。两项本领分开计算，别只看定金高低。

| 人选         | 每项本领的初值范围 | 每项本领的成长率范围 |
| ------------ | ------------------ | -------------------- |
| 初次接活的人 | 150–300            | 110%–145%            |
| 有经验的熟手 | 350–550            | 90%–120%             |
| 老练的行家   | 550–750            | 75%–105%             |

一起做事会增长当前分工的本领，上限1000。实际增长看各人的成长率：同样得到10点基础经验，成长率120%的人会增加12点。另一项本领不会跟着增加。受伤会削弱参与行动时的表现，不能参加或已被扣留的人也无法取得成长。

**默契属于具体的两个人**，范围为0–100。换了搭档，就按新两人的经历计算。日后换回旧搭档，先前积累的默契仍在。共同完成行动能让默契增加，在豪劫中最多提高**15%**的分工贡献，可与“知人善任”的**10%**相加。你的本领与身体状态仍会参与判定。

首次聘用要付定金，解雇不会退款。已经付过的人再邀回来，不用再付一遍。换人或交换分工会使旧排演失效，需要重新安排。学到的本领与两人之间的默契会保留，同一组合、同一分工反复排演则不会再给经验。约定进行中先保持人手不变，要调整就回酒馆暂停后再谈。

## 警方悬赏与双向追缉

与格兰特合作后，告示板按信任和开放地点提供案件。每份线索有效72小时，先到目击地点调查，再核对目标身份。可以劝说、追赶，或在冲突中进入原版战斗。汽车需要停在附近，有座位、油量和驾驶资格，不能凭空把目标送到警局。

完成移交后，回警局在08:00–18:00领取赏金。目标受枪伤时，先按现场提示处理伤情。犯罪记录会妨碍接案或领款，与警方合作不会自动销掉记录。

核对身份后，如果不想亲自抓捕，也可以在08:00–18:00到悬赏柜台把可靠线索交给在岗的格兰特。警方接手这次追缉，支付基础赏金的**20%**，信任增加1点，本次委托随之结束。线索费不计抓捕完成或类型进度，不享受赏金猎人奖金，不能再领取同一委托的抓捕报酬。

**赏金猎人**要求当前12类委托每类都实际领款至少一次。告示板和日志显示已完成类型与尚缺名称，重复同一类不能补齐其他类型。补齐最后一类的那单仍按原价支付，之后保持与格兰特合作时，基础赏金增加**15%**。首次核实、移交并领款还可获得**收网**成就。

你可以接兰德里的工作，也可以追缉犯罪目标，但双方并非同盟。犯罪记录严重时，其他赏金猎人也可能在街头追捕你。还没被发现时，可以凭诡术悄悄绕开。失败后仍能交涉、逃跑或反抗。甩掉猎人不会消除罪证，当天也不会再触发这次街头追捕。

## 贝利与米奇

贝利的差事、扣货和威胁可与工厂经营、原有房租关系联动。可以在原版办公室或公寓找到相应入口，是否能谈判取决于口才、经济地位或已取得的独立地位。交钱、拒绝、求助或反抗，按当时选项处理，不会仅凭街头口碑免除旧债。

米奇可以帮你检查消息、分工和风险，仍保留原版名声委托。不要把两份相同传闻当成两个可靠来源。米奇不会自动加入外出行动，也不会替你同意警探或兰德里的要求。

## 银行豪劫

目标是**金融中心银行**。发起新行动前，上面三条约定都要做完并结清，同时启用金融模块、把街头口碑提高到70。需要认识兰德里与伦恩，伦恩好感至少20。兰德里则要充分认可你的资历，好感60、原版黑箱任务累计25次、销赃实收<span class="gold">£8,000</span>，满足一项即可，已经确认的背叛仍会妨碍合作。先约私下会面，再沿原版路线去走私者酒馆，在09:00–18:00继续筹备。

1. 与兰德里、伦恩商量计划。新接下的银行约定会先展开**码头押款**和**市政招待会**，两案都需到现场办事，再回酒馆报告结果。
2. 选择安静行事或公开强攻，核对银行信息、准备用品、进行演练。口才、数学、科学、家务、诡术与身体状态影响准备质量，有包装产线的正常经营工厂还可协助备货。
3. 确认侦察员与搬运员的人选、分工和分成。定金与事后分成分别计算，中途撤回计划不退已经支付的报酬。队员的能力、伤势与两人之间的默契都会影响行动。
4. 两案已有交代、筹备和人手就绪后，周二至周六09:00–17:00到商业街金融中心的银行柜台开始。大厅盘问、内部通道、金库、搬运与撤离分别需要实际选择。冲突会进入原版战斗。开始后可继续处理现场，不会仅因柜台关门强行中断。压力、疲劳、疼痛、醉酒和药物影响会降低表现。
5. 带出的是黄金。脱身后先处理失联的同伙与销赃安排，到了指定日期才可实际出售，再按约分账结案。黄金估值、销金总款、PC实收与已记录开销各不相同。

### 两桩先行大案

| 案件       | 接洽和继续地点             | 时段        | 收尾                              |
| ---------- | -------------------------- | ----------- | --------------------------------- |
| 码头押款   | 走私者酒馆接洽后，到码头   | 09:00–18:00 | 回走私者酒馆如实报告，09:00–18:00 |
| 市政招待会 | 走私者酒馆接洽后，到市政厅 | 14:00–17:00 | 回走私者酒馆如实报告，09:00–18:00 |

正式入场前，两案都需留出超过两小时的营业余量；开始后即使跨过结束时刻，仍可处理撤离。侦察、接近目标、取物和撤离都有各自的选择，潜行与公开冲突会留下不同后果。事后回酒馆报告并结清报酬。失手时仍须报告结果，重新支付筹备费后才能再试。先办妥码头案，再接招待会。两案都完成或部分完成并结清后，银行行动才会开放。

仓库内部先要跨过货垛或侦察通道，再核对运输记录；实地查明的装卸通路会承接到银行入口。取款时可以留下工人的工资，代价是少拿钱；连工资一起取走，会引来更多追赶。招待会则需进入私人展廊、打开内部金库、抄录账户文件，再决定是否拿走客人的抵押物。核实的账户副本会改善银行辨认与交涉，不能只在门口听完介绍便算取得成果。

关系、身份与先前的经历会改变可用办法。格兰特会核验你提供的线索，你也可以保留消息或拒绝继续。

### 银行与黄金

普通用品需要<span class="gold">£1,500</span>，排演另需<span class="gold">£300</span>。正常经营的自家包装工厂能把用品费用降至<span class="gold">£750</span>。三位候选人的定金分别是<span class="gold">£300／£900／£1,800</span>，你需要从中聘两人。定金之外，每人仍按说好的比例分赃。米奇复核一部分计划需要<span class="gold">£600</span>。筹备页保留已记录的实际支出，分账时也会列出扣除这笔钱后的所得。

**知人善任**：聘好能够参加的侦察员与搬运员，并把排演质量做到8或以上。此后两人在侦察、搬运与撤离中的技能贡献提高**10%**。伤势仍会削弱表现，缺了人或有人被扣留时，这份默契也无法生效。查看准备质量和当前把握，再决定由谁负责哪一份工作。

银行内需要逐步通过大厅与内部通道，再处理金库守卫、搬取黄金并与同伙会合。提醒柜员或带开顾客会保护旁人，同时放弃继续隐瞒入场；码头案实地查明的装卸通路可提供另一种入口。阿德里安是否在岗、是否认识你，以及你有没有遮脸，会影响认脸与关系后果。遇上阻碍时，仍可选择交涉、反抗、弃财撤退或交由警方处理。

多拿黄金会增加撤离负担。会合时应实际清点受伤和走散的人：可回头寻找、用敷料包扎，或留下部分黄金扶人离开。决定留下掉队者后，他们不会继续贡献撤离能力。穿过街口后还需找掩护或甩开追踪，最后选择徒步或驾驶备好的汽车离开。谨慎撤离会放弃部分黄金并多花时间。徒步要能行动，驾驶还需车确实停在商业街、燃油和乘客位足够、本人能合法驾驶。撤离失败会损失财物，也可能使你与同伙受伤或被扣留，已付开销与犯罪记录不会消失。

奎恩可以提供公开备案或带编号的私人副本，两者的保密承诺不同；公开账户会影响贝利是否退还押款。拿到注销的担保后，可以回贝利处清账。格兰特会核对可查证的细节，不会因私下约定免除你自己的案件。医院接待处可提供单据与敷料；符合原版预约条件时，哈珀另有付费治疗或留下受伤陈述的选择。

黄金须等到脱身后的指定日期才能交接，通常为第二日。先处理同伙的去向，再在走私者酒馆约买家，约见当日09:00–18:00带货赴约。错过日子必须改约，拖延会压低报价；未交货时仍可改找另一位买家。

验货并非直接按估值换钱。科学用于检查砝码与金料，数学用于核对账目并留下可靠凭据，英语可再争取一次价格，失败也可能被继续压价。确认后的报价不会因重看页面而改变。兰德里介绍的买家先付三成定金，两天后再约尾款；另一位收货人的报价较低，但交货时付清。

尾款拖欠时，可以拿核实的凭据追讨、交涉追回大部分尾款、转让未付债权换取部分现款，或反抗拦路的随从，进入真实战斗。战败不等于欠款消失，也不会把已经交出的同批金条重新变出来。仍可凭文书处理、转让债权，或明确放弃，只按真正收到的定金和追讨款分账。放弃共同货款会损害兰德里与伦恩的信任，未交货就放弃不会记成已经售出。全部销金款先记公账，最终仍找兰德里领取一次个人份额。

日志会区分约见、验货、交货、等尾款、失约与违约；统计分别记录带回／已售金条、估值、固定报价、定金、公账实收和个人分账。已记录开销包含前案筹备与案后调查、救援费用；银行分账减去这些开销，不等于整条长链净利润，前两案的个人报酬已经另行支付。

### 公开材料与行情

码头实际公开冲突／取货事件只影响梅尔街航运，银行事件与复业只影响商业街购物中心。主动公开与金融中心受托账户、仓储担保编号对应的材料，才会追加相关证券的消息；私下查访、封存副本和普通救援不会让所有证券涨跌。公开账户也会让金条更难转手，买家会再压价。市政招待会本身没有确定的发行人，不会凭未知文件虚构公司黑幕或行情。每条事件只登记一次，改约、重看消息或重筹失败前案不能反复制造同一条涨跌。

可以在筹备中联系格兰特，选择举报或协助抓捕，也可以改变自己向谁提供消息。**事先约定协助不等于免罪**：自己的待处理案件仍可能让你被扣留，也会妨碍领取警方报酬。临时告发同样不能抹掉已经参与的犯罪。每次选择都会影响相关人物的信任与后续合作，不能把两边互相冲突的要求同时算作完成。

银行遇袭后，柜台暂停接待两天，账户和贷款不会因此被取消。原版警方仍会追究犯罪。安静路线成功撤离、实际分账，而且全程未报警或被认出，才获得**悄然无声**，中途只潜入成功不算。

筹备保留各动作原有耗时：柜台核对20分钟，用品整理20–30分钟，排演30分钟，介绍人选15分钟，议价和聘用各5分钟。剩余营业时间不足时会直接说明原因，已经开始却被打断，会显示实际耗时，未完成的安排不收费或增长技能。所有安排都需要在收店前完成。

成功分账之后，还自由且能够工作的原班雇员会在走私者酒馆介绍普通订单：侦察员的仓储耗材单基础报酬<span class="gold">£120</span>，搬运员的港口配送单基础报酬<span class="gold">£160</span>。你仍需要沿实际路线取货、运送和取得签收凭据，再回丰收街找兰德里领款。

合作人的熟练度让总报价增加0–20%，合作人分得25%，你领取余下75%，报价在接单时锁定。每名合作人每天介绍一单，接下后占用当天名额，取消也不会退回。迟到或货物争议照常减少双方实领。每份成功领款的订单提供10点基础经验，再按合作人的个人成长率折算，只增加对应分工的本领，上限1000。 这些新收入不会清除银行豪劫留下的犯罪记录。

码头押款发生公开劫夺或冲突后，梅尔街航运会出现一次−2%的消息。银行遇袭及解除临时停业会影响商业街购物中心，悬赏结案与合法供货也会带来相关商讯。具体交易规则见**金融与经营 → 银行与投资**。
