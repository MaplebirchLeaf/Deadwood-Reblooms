### 选择恋人

到**角色 → 态度 → 你把谁视作恋人**选择人物。候选资格取决于各自的关系进度。

| 角色页的意识等级 | 可以保留的恋人数   |
| ---------------- | ------------------ |
| 三级及以下       | 1位                |
| 四级             | 2位                |
| 五级             | 3位                |
| 六级及以上       | 全部当前合资格候选 |

意识变化后，让游戏正常跨日再检查名单。低意识时超额选择，后续会保留排在前面的名额，意识下降也可能移除后面的选择。

在 New World 中，已有「Polyamorous」特质时可以直接选择多位合资格恋人，无需先提高意识。New World 的恋人排序取名单前六位。

### 排序与相处

- 点击已选人物可移除，拖动或使用左右箭头排序。排在前三位的人会承担原版主要、次要与第三恋人的位置。
- 模组的多恋人互动也包含第四位及以后的恋人。
- 启用果园并与雷米明确确认交往后，雷米也可进入候选名单，详见果园章节。
- 约会、留宿与同住仍需人物当时愿意、在场并满足各自条件。自购房同住见金融章节。
- 有「终身相伴」特质时，更换伴侣可能造成精神负担，确认前会显示提示。

### 同心吊坠

戴着同心吊坠，在罗宾、惠特尼、凯拉尔、悉尼、艾弗里、艾利克斯、格威岚、雷米或月羽的普通交谈选项中，可以主动展示里面的照片。每人每天一次，不额外耗时。需要人物在场、能够交谈，战斗、强制遭遇和过度紧张时不出现。

照片是本人、别人或空着时，对方的反应各不相同。可以解释，也可以合上吊坠，照片在镜子处更换。

月羽在神社廊下、屋舍中清醒相处、果树边劳动或下山采购时，都可以交谈。在各处展示共用当天次数，睡觉、洗澡或未获邀请潜入屋舍时不出现。

独自在镜子前查看照片时，描述会随压力、创伤、疲劳与部分人物近况变化。

关系足够亲近、已选作恋人且吊坠里放着对方照片时，可以说想把照片带在身边，增加1点好感、减少2点压力。雷米只在正常交往时有这一回应，囚禁与斯德哥尔摩不算。凯拉尔受到安抚时，嫉妒会略微降低。

### 社交头像

社交卡片增加小头像，表情与装束随人物状态变化。场景中的大立绘由「NPC侧边栏立绘」控制。
