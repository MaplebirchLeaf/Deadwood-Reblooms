### 选择恋人

到**角色 → 态度 → 你把谁视作恋人**，从当前合资格的人物中添加。人物先要达到自己的关系条件，认识、好感高或有社交头像都不代表已经成为候选。

| 角色页的意识等级 | 可以保留的恋人数   |
| ---------------- | ------------------ |
| 三级及以下       | 1位                |
| 四级             | 2位                |
| 五级             | 3位                |
| 六级及以上       | 全部当前合资格候选 |

意识变化后，让游戏正常跨日再检查名单。低意识时超额选择，后续会保留排在前面的名额，意识下降也可能移除后面的选择。

在 New World 中，已有「Polyamorous」特质时可以直接选择多位合资格恋人，无需先提高意识。名单前六位会同步到 New World 的原生恋人位置。

### 排序与相处

- 点击已选人物可移除，拖动或使用左右箭头排序。排在前三位的人会承担原版主要、次要与第三恋人的位置。
- 第四位以后也能被扩展恋人玩法识别，但只认前三位的原版剧情仍看排序。
- 启用果园并与雷米明确确认交往后，雷米也可进入候选名单，详见果园章节。
- 约会、留宿与同住仍需人物当时愿意、在场并满足各自条件。自购房同住见金融章节。
- 有「终身相伴」特质时，更换伴侣可能造成精神负担，确认前会显示提示。

### 社交头像

社交栏的人物卡片会增加小头像，表情与装束随人物状态变化。它们帮助辨认人物，不改变关系数值。场景中的大立绘由「NPC侧边栏立绘」另行控制。
