### 前置条件与入口

启用「更多恋人与社交栏头像」并重载，在 **角色 → 态度 → 你把谁视作恋人** 调整名单。候选资格、意识名额和选择名单是三件事，必须分别满足。

- **候选资格**：先完成该人物的原版关系条件，才能出现在可选名单。
- **意识名额**：意识决定能保留多少位恋人，好感高不能代替意识。
- **正式选择**：人物可以成为恋人，不等于 PC 已把对方加入名单。约会与同住还会读取这项选择。

### 原版意识等级与恋人名额

在角色属性页查看「意识」的等级和文字描述。以原版显示为准，不使用内部恋人判定的编号。

| 原版意识等级 | 原版描述                                 | 可保留恋人数                     |
| ------------ | ---------------------------------------- | -------------------------------- |
| 三级及以下   | 从单纯、一知半解到「你对性有基础的了解」 | 1                                |
| 四级         | 「你对性有了更深层次的理解」             | 2                                |
| 五级         | 「你比其他人见得更多，也知道得更多」     | 3                                |
| 六级         | 「你凝视着堕落的深渊」                   | 全部当前合资格候选，不止四位     |
| 七级         | 「你对性的理解已经超然于世」             | 与六级相同，不再额外增加名单范围 |

<span class="lewd">想保留多位恋人，先达到对应意识等级。</span>六级就能开放扩展名单，不必等七级。名额足够也不会让关系尚未解锁的 NPC 自动成为候选。

原版在跨日结算时更新恋人使用的意识判定。刚在事件中升档后，让游戏正常跨日，再回态度页检查名单与提示。

### 意识怎么变化

本模块不提供“购买名额”或单独训练意识的按钮，沿用原版意识变化。部分神殿阅读、忏悔分支、成人用品店工作及原版经历会提高意识，具体以行动后的意识提示为准。并非每次阅读或工作都固定增长同样数值。

意识也会下降，例如神殿「忏悔你的疑虑」降低意识，病院部分镜面剧情也会降低。纯洁、淫荡度、好感与意识各自记录，不能用提高其他数值来代替这张表。高意识还会影响原版其他剧情和状态，请留意相关特质与提示。

### 添加、移除与排序怎么做

1. 在可选名单点击人物，加入已选名单。先按上面的意识表确认能保留的数量。
2. 点击已选人物可移除。移除的是 PC 的恋人选择，不会清空好感或撤销已经发生的关系剧情。
3. 拖动已选人物排序，或用左右箭头调整。排在前面的三人分别同步为原版主要、次要、第三恋人。
4. 第四位以后由扩展恋人判断识别，但只读取原版前三槽位的剧情仍受排序影响。希望作为主要对象的人放在第一位。
5. 回实际人物地点使用约会、同住等入口。这些行动仍检查自己的关系、日程、邀请和身体状态。

<span class="red">低意识时超额添加不能稳定保留。后续检查会按当前名额保留名单前几位，裁掉后面的选择。</span>意识下降并跨日更新后也会发生相同情况，重要人物应提前排到前面。当前界面并不是达到上限就把候选按钮全部变灰。

名单保存在当前游戏存档。读另一份存档会恢复那份名单，不与框架模块开关混为一谈。

### 社交栏头像有什么效果

在原版社交栏的已有 NPC 卡片查看小头像。表情、装束与关系图标会按人物状态选择，罗宾创伤与支配、凯拉尔好感与嫉妒、悉尼纯洁与堕落等都可能改变差分。这些是显示效果，不增加好感或解锁关系。

| 人物               | 头像变化                                                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| 格威岚             | 随原版关系描述显示拒绝、等待、仪式、亲近、思念或失望等表情。已知转化且原版显示发情时，使用对应差分 |
| 梅森               | 根据原版对你的评价，区分普通、鼓励、认可和不同阶段的欲望表情                                       |
| 巨鹰               | 根据依恋、好感和支配，区分挽留、求偶、失落与伴侣等表情                                             |
| 悉尼的象牙怨灵拟态 | 黑发与草莓金发分别有蓝眼、红眼差分，沿用原版怨灵状态选择                                           |

夜魔提供无毛鳞片的兽形头像，以及男女两种乱发、双角的怪物形头像。头像跟随原版记录的形态，不改变原版社交栏的出现条件。

场景中的较大立绘属于「NPC 侧边栏立绘」模块。社交头像出现，不保证当前场景也有立绘，反过来也一样。

### 常见问题

| 问题                     | 怎么处理                                             |
| ------------------------ | ---------------------------------------------------- |
| 想选第二位却保留不住     | 意识四级，正常跨日后再核对                           |
| 想选四位或更多           | 意识六级，不必等七级                                 |
| 意识够但人物不在候选名单 | 核对上表的原版资格与监禁、抛弃等状态                 |
| 选择后又少了几位         | 检查意识下降、跨日更新及名单顺序                     |
| 已选恋人却没有同住选项   | 去「原版增强」核对房源、床位、人物地点和冲突条件     |
| 头像没显示               | 确认原版社交卡片已出现、模块已重载及图像资源加载正常 |
