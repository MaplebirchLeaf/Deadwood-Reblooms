### 前置条件与路线选择

启用「惠特尼拓展」并重载。救援与恋人日常是两条独立路线，不能把“恋人”当成已救援，也不能把“已获救”当成原版住所剧情已完成。

| 路线         | 入口                       | 必需状态                           |
| ------------ | -------------------------- | ---------------------------------- |
| 地下妓院救援 | 地下牢房门边               | PC 与惠特尼同时被囚禁              |
| 救援后重逢   | 学校前庭                   | 已带惠特尼成功逃离，人物能正常活动 |
| 码头散步     | 码头相处                   | 惠特尼恋爱关系、白天、PC 未裸露    |
| 公寓日常     | 原版敲门与进入公寓后的谈话 | 已推进住所关系、恋爱关系和好感     |

### 地下救援：具体步骤

1. 两人被关在地下妓院时，在牢房选择 **听门外动静（0:01）**，确认惠特尼声音。
2. 选择 **等守卫开门（0:30）**，寻找混入后台的机会。
3. 到后台后选择解开扣环或推开守卫，两者约五分钟，分别检查诡术与体能。
4. 罗宾若也被囚禁，可以分散守卫并一起逃离。
5. 确认最后是带惠特尼一起逃出，独自离开不计营救成功，也不解锁对应成就。

<span class="red">逃离不是必定成功。</span>相关能力与罗宾协助会提高机会，失败返回牢房并增加压力、疼痛与创伤。可以重新尝试，但不要把代价忽略掉。模块不会为了开启路线把人物强行送进地下妓院。

救援沿用原版诡术、体能检定与练习收益。罗宾的动静会降低第一道诡术检定的难度，神殿负担仍可能令检定失败。重复查看已结算的救援页面不会再次练习或受伤。

### 获救后重逢与校园日常

成功营救后，在 **上学日 07:00–18:00 的学校前庭**查看重逢。先问惠特尼怎么样，恋人可有牵手等回应。后续日常每天一次，按人物状态与当天事件开放。

共同散步和谈话读取恋人关系，风纪委员徽章会改变回应。前庭被原版事件占用、惠特尼尚未恢复可活动、PC 裸露或当天已聊过时，不会重复出现。

### 码头：在哪里、怎么做、什么效果

惠特尼为恋人、可正常活动或已获救，PC 没有裸露时，在 **09:00 至 17:00 前、非夜间的码头**查看新增相处选项。每天一次，进入后按对话选择回应，作为关系日常，不新增一套码头技能或永久工作。

### 公寓：门口与听音乐

**门口日常**需要恋爱关系、充分熟识和原版住所进度达到能深入相处的阶段。到原版敲门页面查看，黎明或符合其在家安排的白天开放。上学安排、天气与特定日期仍影响人物在不在家。

**听音乐**在公寓内部的原版谈话中，每天一次。坐下来听可以增加好感并减轻压力，询问曲子以对白为主，不会因此解锁歌唱技能。

### 效果、限制与排查

本模块补充营救、重逢与生活，不取消原版霸凌关系、监禁或人物日程。

- 救援缺失：两人是否真的同时被关，是否先听门外声音。
- 重逢缺失：是否成功带惠特尼逃出，今天是否上学日，人物是否恢复活动。
- 公寓缺失：是否完成原版住所进度，而不只是选择了恋人。
- 日常缺失：核对地点、时段、裸露、原版事件与每日次数。
