### 前置条件

启用「动态音乐」模块，并安装文件名含 **deadwood-reblooms-audio** 的独立音频包。本体只提供播放调度，音频包提供配置和曲目，缺其中一项都不能完整播放。

### 在哪里开启、怎么做

1. 在加载器确认音频包已加载，不能只把文件留在下载目录。
2. 模块开关修改后先存档并重载。
3. 到 **模组设置 → 动态音乐** 勾选启用。模块启用与这里的播放开关是两层控制。
4. 分别调音乐与环境声音量，默认分别为 50%、25%。一条为零不会自动静音另一条。
5. 在游戏页面点击一次，允许浏览器播放音频，再进入有对应配置的场景。

### 什么时候会切换

| 音频层 | 优先顺序                               | 触发依据                 |
| ------ | -------------------------------------- | ------------------------ |
| 音乐   | 战斗 → 日蚀 → 血月 → 流星雨 → 普通昼夜 | 当前游戏状态与音频包配置 |
| 环境声 | 雷暴 → 雨 → 雪天风声                   | 当前天气与音频包配置     |

环境声独立于音乐，时间、天气与场景变化会刷新播放状态。不是每次点击都会随机换一首曲子。

### 效果与限制

只改变声音，不更改天气、日期或人物约会。日蚀与流星雨的发生看「天体异象」，听到曲目不等于获得约会资格。普通血月不用额外开日蚀开关。

### 没有声音时怎么查

按 **音频包加载 → 模块重载 → 播放启用 → 两条音量 → 游戏主音量 → 网页静音／浏览器自动播放 → 资源报错** 检查。只缺某个天气的声音时，先核对音频包是否配置了对应资源，调高音量不能补出不存在的曲目。
