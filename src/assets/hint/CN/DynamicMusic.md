### 开始播放

请使用 **5.4.9 或以上**的框架，本体和独立音频包使用配套版本。

1. 在加载器中加载**枯木逢春音频包**，并启用动态音乐模块。
2. 到**模组设置 → 动态音乐**勾选「启用动态音乐」。页面会显示音频包是否已加载。
3. 分别选择「音乐」「环境音」和「音效」，默认音量为 **50% / 25% / 35%**。
4. 点击游戏页面，让浏览器允许播放声音，再正常游玩。

音频包是可选的。没有加载时，动态音频保持静音，游戏仍可正常游玩。

### 音乐、环境音与音效

| 声音层     | 内容                                         | 播放方式               |
| ---------- | -------------------------------------------- | ---------------------- |
| 音乐       | 地点、昼夜与遭遇配乐                         | 按当前场景选择一首     |
| 地点环境音 | 海浪、街声、鸟鸣、荒原风、地下水声与机械底噪 | 按地点选择             |
| 天气环境音 | 露天雨雪、雷雨与隔窗雨声                     | 可与地点环境音叠加     |
| 音效       | 打击、开火和衣物变化                         | 发生实际变化时短暂播放 |

海边下雨时，海浪和雨声可以同时播放。没有雨雪时，荒原和城堡废墟会响起风声。排水渠有持续流水，旧下水道则以较轻的滴水声为主。进入室内会停止露天雨雪与鸟鸣。

孤儿院的卧室、浴室和神殿宿舍有隔窗雨声，雷雨时伴着间歇的远雷。环境音随场景渐变，连贯播放。

豪劫、追逐和危险遭遇会优先使用紧张配乐，自愿互动不会一律套用搏斗音乐。没有匹配规则时保持安静。

音效包括换装、打击和开火，没有人声。鼠标与数字快捷键操作都可触发。

### 音量与播放器

**音乐音量**控制配乐，**环境音音量**共同控制地点与天气底声，**音效音量**控制动作短音效。音乐播放器中的**总音量**和静音同时影响这些声音。

- 想听清配乐，可以降低环境音和音效。
- 想保留雨声与海浪，可以只关闭音乐。
- 关闭动态音乐总开关会停止本模块的声音，不会清空导入文件。
- **音频包**列表仅展示配乐，环境音和音效由场景与动作自动选择。
- **导入音频**可以播放自己的本地文件。「清空导入音频」只删除导入库，不删除内建音频包。
- 动态选曲可能在场景变化后接管手动播放的曲目。想持续播放自己的音乐，可以关闭音乐层，同时保留环境音和音效。

### 没有声音时

先检查配套音频包、模块与所需声音层是否开启，再检查分层音量、总音量、网页静音和浏览器播放权限。某些场景会刻意保持安静，并非每次点击或每个战斗回合都有音效。
