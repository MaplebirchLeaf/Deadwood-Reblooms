神殿与农场首次整理花一小时。后续选「继续开垦」，每次40分钟，神殿新树位需累计80分钟，农场需120分钟，进度可以分次完成。神社的土地已经整理好，陪月羽检查10分钟即可使用，没有额外开垦位。

### 找种源、种下与照料

苹果、梨、桃子、李子、橘子与柠檬的种源，在原版采摘时有机会发现，酸橙在神殿花园采集时发现，樱桃种源在超市购买，<span class="gold">£1,000</span>。**种源只解锁一次，之后播种不重复消耗种子。**

选好树种，将工具拖到树位，手机可先点工具，再点树位。只在已开垦空地播种，点树位可查看水分、肥效、土壤与生长。

- **浇水**：缺水时补足七天水分。雨水会补水，原版农场九块田都接通灌溉后，农场果园也自动供水。月羽会照料神社的两块地，不在活动状态时停止照料。
- **幼树施肥**：一袋肥料持续30天，有水时生长速度加倍。缺水会停止生长，施肥不能替代浇水。
- **成树施肥**：植物护理C级后可以改善土壤，提高产量，通常肥效结束会恢复，园艺大师可永久保留改良。
- **采收**：一次收走该树已有成熟水果。铲除需确认，会失去果树与枝头收成，已经开垦的土地保留。

肥料和原版农田共用。夜间搜索码头货物、能辨认肥料后可冒险偷取，特殊集市园艺摊有时出售一袋<span class="gold">£1,000</span>。

### 成树、季节与血柠

大多数果树累计28个有水生长日成树，樱桃26天、酸橙31天。成树每七个有水生长日结一批，枝头最多积存三批，挂满后暂停新增，及时采收便可继续。

| 果树       | 丰产季节         |
| ---------- | ---------------- |
| 苹果、梨   | 秋季             |
| 桃子、橘子 | 夏季             |
| 李子       | 夏季、秋季       |
| 樱桃       | 春季             |
| 柠檬、酸橙 | 春季、夏季、秋季 |

其他季节，包括冬季，产量为丰产季节的一半。护理技能、土壤与树龄也影响收成，成功采收三次、九次时分别进入更高产量阶段。

柠檬树在血月那夜新结的果实会成为**血柠**。已有柠檬不改变，血柠也不会在天亮后消失，挂满三批时先采收，才能留出结果空间。

### 艾利克斯与雇工

艾利克斯白天处理账务时，可到果园一起巡视、休息或分享苹果，每天共一次。也可以请其帮助开垦、浇水或采收，每天共一次，缩短工作时间。

农场果园开放后，到酒馆花30分钟寻找照料雇工。周薪<span class="gold">£250</span>，雇用时预付七天，可以续到最多十四天，未付薪便停工，辞退不退已付工资。

雇工每天08:00照料，默认只浇水，可另选自动采收和使用现有肥料。不会播种、开垦或铲树，也不会替PC增加护理经验。08:00至中午可在果园询问实际工作记录，袭击时暂停。

完成**三笔罗宾饮品店供货订单与三笔艾利克斯长单**，获得「**货路熟手**」。此后普通批量水果交货由30分钟缩短至20分钟，交货链接会显示实际耗时。每日100个限额、收购价、库存保留与长单押金照常。

集市新增水果熟客每天可买五个已摆出的水果，按原价付款。农场普通收购、饮品店与熟客的销售明细都记在账本里。

### 在自有房产小酌

把果园装好的酒留在库存中，即可在自有房产的起居室、休息室、厨房或酒窖开瓶，也可选原版红、白葡萄酒。选在家的同住恋人作伴，没有同伴时可以独饮。每次用一瓶、耗时20分钟，酒量与耐受沿用原版，同日首次与该恋人小酌增加1点好感。

小酌之后可继续聊天、收好酒杯，或双方清楚同意后相伴片刻。后续选择不再开酒，穿衣与脱衣由玩家决定。

### 后期自动照料与运输

启用金融并持借记卡后，可授权照料雇工从银行续薪，另找送货工处理早班交货，两项需主动开启。余额不足便暂停，不补收停工期间的工资。

运输仍用普通收购的七成价和每日100个总额度，每趟扣<span class="gold">£5</span>运费，净收入进银行。只送保留数量与未到期订单之外的水果，血柠不自动运输，不会自动签长单或缴押金。当天已知的农场袭击暂停早班照料、采收与运输，回执会说明停工，薪期与断薪七天离职仍照常结算。恢复后不补做停工班次，也不因眼下遇袭改写此前日期的工作。辞退照料雇工会一并取消续薪和运输安排。

启用果园模块后，白天到骑术学校选择「走近雷米」，**不必先开放种植土地**。约谈需避开临近关门、战斗与突发事件。
