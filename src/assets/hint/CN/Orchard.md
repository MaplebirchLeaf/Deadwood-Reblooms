### 前置条件

启用「果园」模块。神殿需要修士或祭司身份，并把花园清理到满值。农场需要完成原版全部九块田地的开垦。满足条件会出现解锁事件的入口，完成整理土地的剧情后才正式开放。

### 在哪里、如何解锁

- **神殿花园 → 跟随神殿成员走到花圃后面 → 一起整理土地 → 果园**：初始开放五个树位，其中一处已有成熟李子树，另外四处为空地，最多六个树位。李子树全年结果，夏季、秋季产量较高，开放时不附带积存水果。采收时自己带走约一半水果，其余交给厨房。有交给厨房的收成时，也会获得恩典。
- **农场田地 → 去找艾利克斯商量种果树 → 一起整理土地 → 果园**：初始开放三个树位，最多十二个。收成归你，仍受农场袭击与危险事件影响。
- 农场事件要在艾利克斯于农舍处理账务时触发。若对方正在忙其他工作，稍后再来。
- 两处事件都需要白天、双臂能够活动、衣着合适且压力没有达到昏倒的程度。首次与对方划定范围、整理土地需要一小时，沿用原版劳动的体魄与疲劳结算，神殿开放五个树位，农场开放三个树位。
- 已经开放的神殿果园不会因为花园再次需要清理而关闭，但你仍需保有修士或祭司身份。

### 逐步开垦土地

<span class="gold">六个和十二个树位是果园的容量上限，不是第一次进园就全部可种。</span>神殿从五个树位开始，农场从三个树位开始。使用「继续开垦」链接，逐个开垦紧邻的下一处土地。

- 每次开垦四十分钟，沿用原版独自开垦的体魄与疲劳结算。神殿每个新树位共需八十分钟，农场共需两小时，可以分多次完成。
- 每个树位独立保存进度。离开、睡觉或中途遇上事件，不会抹掉已经完成的工作。未开垦的土地不显示在图中，完工后才会增加一个树位。
- 开垦不扣钱或肥料，也不增加植物护理经验。未开垦完成的土地不能播种、浇水、施肥或采收，不需要点选这些土地。
- 已经开垦的土地不会因为铲掉果树重新变成荒地。铲子用于已种树位时，需要确认才会移除果树。
- 全年都可开垦与照料果树。夜间、曝露、双臂受缚与压力限制仍然有效，每次工作后原版昏倒或农场袭击也照常触发。

### 种子从哪里来

种源只需要解锁一次。**解锁后可以反复播种，不消耗种子库存，也不用每次买幼苗。**两处果园共用已经发现的种源。

| 树种                             | 解锁方式                                                                   |
| -------------------------------- | -------------------------------------------------------------------------- |
| 苹果、梨、桃子、李子、橘子、柠檬 | 在原版采摘这些水果时，有机会留下种子。植物护理等级越高，发现种子的机会越大 |
| 酸橙                             | 神殿花园工作中被安排采集酸橙时，留下种子                                   |
| 樱桃                             | 超市正常营业时，购买一次樱桃种子，之后永久解锁                             |

不需要先开放果园才能发现种子。原版吃水果、烹饪、赠礼、商店买水果和领取果园收成不会代替采摘解锁。尚未发现种源时，播种工具不可用，可以先在野外采摘或去神殿花园工作。

果园下方的选择框只显示已解锁树种。切换树种不会改变已经种下的树。特殊种源的购买入口不会出现在关店、夜间潜入或昏倒剧情中。

### 如何操作

每个树位横占三块土壤。图标与土壤块均为原尺寸 30×30，窄屏自动把完整树位换到下一行。右侧工具可以拖到树位使用，手机也可以先点工具，再点树位。

| 操作     | 前置条件                                            | 效果                                           |
| -------- | --------------------------------------------------- | ---------------------------------------------- |
| 播种     | 已开垦的空树位、已解锁所选种源                      | 种下对应果树，种源继续保留                     |
| 浇水     | 果树、土壤水分已经耗尽                              | 补足七天水分，幼树与成树均需供水               |
| 施肥     | 幼树、持有肥料、没有剩余肥效                        | 消耗一袋肥料，三十天内加快有水幼树的生长       |
| 施肥     | 成树、植物护理达到 C 级、土壤尚可改良且没有剩余肥效 | 消耗一袋肥料，三十天内提高一级土壤质量         |
| 采收     | 树位显示果实图标与数量                              | 收取这棵树积存的全部成熟水果，保留果树         |
| 继续开垦 | 紧邻已开垦土地的下一处待开垦树位                    | 完成四十分钟开垦，保存进度，全部完成后才能种树 |
| 铲子     | 已种树、确认移除                                    | 清空树位，不退回肥料或枝头收成，保留已开垦土地 |

果园使用原版袋装肥料，与原版农田及孤儿院菜圃共用库存。幼树施肥和成树土壤改良每次都消耗一袋，并计入原版肥料使用次数。果园内不出售肥料，切换树种不推进时间。

- **码头**：夜间潜入并搜索货物。植物护理达到 C 级才能辨认肥料，每次偷取一袋需要五分钟，会增加盗窃犯罪度，潜入本身也有风险。
- **特殊集市**：园艺摊位有时会出售一袋肥料，价格为 **£1000**，不是随时供应。
- **DoLP 可选来源**：若使用 DoLP，农场的堆肥箱也能产出肥料，需要按该版本的原版条件建造并使用。普通原版没有这项入口。

播种、浇水、施肥、采收和铲除都会消耗游戏时间，并增加少量疲劳与植物护理经验。开垦另按上述体力劳动结算。无效操作不扣材料、不增加经验，也不推进时间。夜间、双臂受缚和裸露时无法作业。压力过高或农场遭袭时先处理原版事件。

### 幼树如何生长

提供八种果树。幼苗长成树苗，再成为成树，各阶段都有独立的 PNG。樱桃成熟稍快，酸橙稍慢。

- **水分**：浇一次水可以支持接下来的七天生长与结果。详情显示剩余水分天数，耗尽后幼树停止生长，成树暂停结果进度。降雨时，雨水会补足果树的水分，不需要先进入果园。一次跳过多天时，不会把最后一天的雨水补算到此前每一天。
- **幼树肥料**：一袋肥料维持三十天，让有水幼树每天的生长进度加倍。施肥不能代替浇水，也不会让幼树立即成熟。肥效用尽后可以再次施肥。
- **进度**：点选树位可以查看生长进度条。没有照料只会延缓生长，不会立刻失去果树。
- **季节**：不影响播种、幼树生长、浇水或施肥。冬季照常照料，季节只影响成熟果树的新果实产量。

### 农场灌溉与帮手

- **灌溉**：原版农场的九块田地全部接通灌溉后，果园也能共用水源，自动补足幼树与成树的水分。神殿果园仍需浇水或等待下雨。
- **艾利克斯**：白天、衣着合适且能够干活时，如果艾利克斯正在农舍处理账务，可以每天请对方帮忙一次。一起开垦用二十分钟完成四十分钟的进度。一起浇灌一棵缺水果树用两分半钟。一起采收一棵树用五分钟。三种帮助共用每天一次的机会，农场袭击时不可用。
- **果园雇工**：农场果园开放后，可以在酒馆的正常菜单中花三十分钟寻找帮手。这是模组新增的独立雇工，不使用原版守卫的职位、薪资或人物记录。
- **薪资**：每周 **£250**，雇用时预付七天，之后可以续付一周。剩余薪期不超过七天时才可提前续付，最多预存十四天。到期后停工，不累积欠薪。续薪从未到期的薪期末尾或当前时间开始。辞退需要确认，已经支付的薪资不退还。
- **工作**：每天早上八点检查一次，水分耗尽后才给果树浇水。可以改为同时采收成熟水果，收成直接进入你的原版食品库存，图下显示最近一次照料的日期、浇水树数、用肥数量与采收数量。真正遭到袭击期间暂停，冬季照常浇水与采收。
- **汇报**：早班完成后，上午八点至中午可以在农场果园「问问雇工果园的情况」。需要有效薪期、衣着合适、能够干活且没有农场袭击。雇工会说明实际浇水与采收的结果，记得你是否把采收留给自己，并提醒不当季的果树产量较少。雨水或灌溉代替浇水时，工作记录也会说明。其他时段仍可查看最近一次的记录，交谈不会重复领取收成。
- **自动施肥**：在果园图下选择「允许雇工使用你的肥料」。之后早班会给肥效耗尽的幼树补肥，成树则沿用 C 级护理与土壤可改良的要求。每棵消耗现有库存的一袋，肥效未耗尽时不会重复使用，也不会购买或透支肥料。缺料会在记录和交谈中提示。可随时改为自己施肥，安排从下一次早班生效。
- 雇工不播种、开垦或铲树，不给 PC 增加疲劳或护理经验。神殿果园不能雇用这名工人。

### 树龄、土壤与产量

成树每积累七天有水的生长，结出一批水果。成为成树的当天才开始新的结果周期。**沿用旧果园的产量规则**：植物护理技能决定随机产量的范围，树龄、树种和土壤质量进一步影响收成。园艺大师特质与原版收成倍率设置也会生效。

- **树龄**：刚结果的树产量较低。成功采收三次后长成中等果树，九次后长成大果树，产量上限继续提高。一次收走多批积存的水果算一次采收。铲掉重种会重新积累树龄。
- **树种**：樱桃沿用旧版的额外产量加成，其余已提供果树沿用各自的数据。
- **土壤**：开放果园时确定每块土地的基础质量。详情沿用原版的贫瘠、普通、肥沃或沃腴土壤描述。铲树和重新进园不能重抽质量。
- **成树施肥**：植物护理达到 C 级后，可把土壤改良一级，最高为沃腴。肥效持续三十天，期间不能重复施肥，不会改变已经结出的水果数量。
- **肥效衰退**：普通人的土壤改良在三十天肥效结束后恢复基础质量，期间采收不会消耗肥效。园艺大师的土壤改良永久保留，但继续改良仍要等当次肥效结束。铲树会清除普通人的临时改良。

果实进入原版食品库存，可以按原版规则食用、烹饪、赠送或出售。

### 丰产季节

| 果树       | 丰产季节         |
| ---------- | ---------------- |
| 苹果、梨   | 秋季             |
| 桃子、橘子 | 夏季             |
| 李子       | 夏季、秋季       |
| 樱桃       | 春季             |
| 柠檬、酸橙 | 春季、夏季、秋季 |

选择种源后，界面会显示该树种的丰产季节。**丰产季节为正常产量，其他季节（包括冬季）为正常产量的 50%，取整计算。**季节不会阻止成熟果树结果，也不会改变已经积存的水果数量。成树也需要水分，七天补水一次。施肥改善产量，不是每次结果的必要条件。

### 结果周期与收成缓存

每棵成树有独立的七天结果进度，最多留住三批收成。有水时，完整缓存对应三个结果周期。详情显示距离下一批果实还需多少天。

- 树位上的数字表示实际水果数量，满三批时，详情提示枝头已经挂满水果。
- 满三批后暂停新增收成，原有水果保留，不会继续无限堆积。
- 采摘会一次收完该树的成熟水果，腾出空间后继续按结果周期生长。
- 换季不会清空或重新计算已有水果，白天仍可采收。
- 查看界面、重复点击与读档不会多结算一天。长时间睡眠会逐日处理实际跨过的日期。

### 血月与血柠

柠檬树遇上血月，**那一夜新结的果实会成为血柠**。血柠使用原版图标与物品效果，产量按同一棵柠檬树计算。

已有普通柠檬不会改变，血柠也不会在天亮后变回柠檬。同一棵树可以积存普通柠檬与血柠，详情会分别显示数量。满三批缓存时不会新增血柠，想留出这一夜的结果空间，需要提前采摘。其他果树与酸橙不受这项变化影响。

### 找不到入口或无法操作

检查模块是否启用并已重载，再检查神殿身份、花园清理或农场开垦进度。农场初次邀请还需要艾利克斯正在处理账务。

种源尚未解锁、土地尚未开垦、树位已占用、水分已补足、仍有肥效、土壤已经达到最高质量、护理等级不足、没有成熟水果或作业条件不满足时，对应操作不会生效。开垦只允许按顺序处理紧邻的下一处土地，通过「继续开垦」链接继续工作，开始开垦后会显示进度条。图下汇总可采收与缺水的树，点选已开垦树位可以查看土壤状态。农场袭击需要先回到田地处理。

### 水果库存、集市与农场交货

- **入口**：已开放果园中的「水果库存与销售」。读取原版食品库存，野外采摘的同类水果也可以使用。神殿分给厨房的收成不会进入玩家库存。
- **集市**：逐个品种选择是否摆出，沿用原版集市展示设置与销售事件。批量交货的保留数量不会限制原版摆摊。不想在集市卖的品种应选择「不在集市摆出」。
- **保留数量**：填写每种水果至少留下多少个，再点击该行「保存」。农场交货只扣除超出保留数量的部分。
- **批量交货**：在农场果园，艾利克斯负责行政工作且白天能够正常工作时可办理。按原版每种水果售价的七成收购，农场每天合计最多收购100个。每次交货花费30分钟，收入按农场交易结算。袭击、昏倒和无法劳动时不可交货。
- **账目**：记录批量收入、种源购买和雇工薪资，保留最近40笔交货明细。旧存档不会推算过去的开销。集市收入与共用肥料不计入此账本。

### 饮品店供货与集市熟客

- **饮品店入口**：罗宾拓展已启用、饮品店开业，且罗宾健康并在店内时，店铺菜单出现「商量水果供货」。果园至少开放一处。不要求两处都开放。
- **试单**：选择柠檬或橙子，对应现有饮料菜单。首次十个，成功交货后再接的订单为二十个。三天内交货，每七天最多约定一单。每单价格在约定时固定，采用原版售价的七成。
- **付款与库存**：保留数量照常生效。货款从罗宾经营资金扣除，并保留原有房租保护。缺货或店内资金不足不会扣库存。交货花十分钟、增加罗宾好感，并抵扣下一次正常饮品补货 £5，不能叠加。水果不会直接替代可可、香料等全部原料。
- **取消与逾期**：无法供货可以回店说明取消，不扣好感，也不会立即生成新订单。期限过后订单失效，罗宾会说明已找供货商。下次订单仍遵守七天间隔。
- **集市熟客**：原版「管理摊位」中可招待买水果的客人。客人每个游戏日最多成交一次，买五个已摆出的水果，按原版售价付款，花二十分钟。使用同一份 per_npc 人物记录，成交次数推进初识、再次来访与熟客对白。保留数量仍只限制供货，集市成交遵循摆出设置。
- **农场合作**：艾利克斯安排装箱运输，每天首次成功交货增加一次好感。拆成多次交货不会反复刷好感。
- **销售明细**：饮品店订单与新增熟客成交也记入果园账本。原版其它集市销售仍由原版记录，避免重复计账。

冬季热巧克力需求较多，饮品店的重复水果订单减半。试单数量不变。已经约定的订单保留签单时的数量与价格。熟客第三次成交后会优先购买初次买过的水果。该品种没摆出或不足五个时，会改买其它已摆出的品种。销售明细标明农场、饮品店和熟客三个渠道，旧记录保留为普通销售。

### 艾利克斯的水果长单

在农场果园的 **水果库存与销售** 中，艾利克斯能够安排发货时选择商量长单。选择已解锁水果与整批数量，核对报价，再缴现金押金预留一周的发货位置。签单时锁定单价，之后行情或库存变化不会重算合同。

交货要一次交齐，标记保留的水果不会被取走。按时交货后收到货款并退回押金。超时则失去押金，并影响艾利克斯对你的信任。长单与每日普通收购使用不同的安排，不占普通收购额度。

近期为罗宾饮品店完成水果订单，会带来额外周销售。逾期未供货则不再享有这项增收。已有果园销售记录可以用于金融中心的经营贷款申请，借款仍由 PC 负责偿还。

### 后期的续薪与运输

启用金融功能并持有借记卡后，可授权照料雇工自动领薪，并在果园另找送货工委托早班运输，两项默认关闭。送货工沿用同一人物，按趟收费。重访可以查看最近收货记录、结束或恢复安排。照料雇工薪期结束后首次可工作的早班从银行扣 £250，支付成功才重新开始七天薪期。停工日期不补收工资。余额不足或卡片不可用时停工，可以补款后恢复。辞退照料雇工时，同时取消自动续薪和运输安排。

运输使用与手动交货相同的七成收购价和每日总计 100 个的额度，每次另收 £5 运费。血柠不参与自动运输。其它水果只运输超出保留数量与未到期订单所需数量的部分，毛收入不足以覆盖运费时不发货。货款扣除运费后进入银行，明细记录收入与运输支出。不会替 PC 获得艾利克斯好感或护理经验。遇袭时停运，也不自动接单、缴押金或交付长单。
