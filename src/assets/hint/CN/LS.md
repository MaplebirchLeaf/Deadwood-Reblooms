| 阶段     | 去哪里                                 | 需要什么                                                                                                  | 获得什么                                       |
| -------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 免听凭证 | 校长办公室 → 贝利办公室 → 校长办公室   | 四科及总体成绩达到最高档。礼顿好感至少 10，或已在原版剧情中掌握把柄。贝利通常要求连续三周按时交租         | 缺课不记旷课。各科成绩仍会自然衰减             |
| 风纪委员 | 取得凭证七天后，找礼顿                 | 总体成绩保持最高档。原版社交栏“教师”为**模范学生**，“学校”至少为**很酷**。礼顿好感至少 10，或掌握他的把柄 | 上学日前庭开放晨间值勤。留堂可自行决定是否参加 |
| 学生会长 | 完成五个不同上学日的晨间值勤后，找礼顿 | 校内秩序、学生声望、教职工信任各至少 25                                                                   | 在校长办公室提出着装校规，试行与复核后继续推进 |

**贝利在哪里？**反抗线尚未让他离开孤儿院时，07:00–09:00 到孤儿院办公室申请监护人签名。罗宾路线赶走贝利后，到倒钩街公寓找他。此时不再要求三周交租。礼顿和贝利都签字后，**必须回校长办公室交表**，凭证才生效。

**风纪委员为什么没有入口？**取得凭证后还要经过七天。申请入口只在礼顿可接待你的上学日出现。温特无须另外推荐。若教师评价或同学评价不足，礼顿会说明要求。掌握礼顿把柄可以代替他的私人好感，不能代替成绩和两项学校评价。

### 值勤、声望与校规

上学日 07:00–09:00 从学校前庭开始值勤。罗宾、悉尼、凯拉尔、惠特尼的事件随各自日程出现。处理方式影响 NPC 关系，以及**校内秩序、学生声望、教职工信任、校内堕落**。每次结算会显示实际升降。

走廊的**学生事务公告栏**查看四项数值、值勤次数和现行校规。前两项社交栏评价属于原版，公告栏的四项属于本模块，两组数值各有用途。担任会长后，向礼顿提出下一档校规，试行一周，再回办公室复核。较开放的校规还要满足支持度和堕落要求。

### 历史展览与联动

完成原版画作事件后，在历史课接温特的项目。顺序是**图书馆查档 → 博物馆核对藏品 → 森林湖调查 → 在家写稿 → 博物馆办展**。打开日志看下一处线索。罗宾或凯拉尔参与时，部分选择和对白会变化。

风纪委员与会长可以在罗宾的店为学生会订饮品。罗宾须在店内，有新品原料，银行账户至少有 £20，每天一次。你也可在自家住宅书桌整理课后资料，或在西里斯庄园书房准备讲解。庄园内的科学技能分支需要达到 500。
