## 理智与恐惧

**理智**影响你能否专心思考，**恐惧**表示你眼下有多害怕。理智范围为−500～1000，初始1000。恐惧范围为0～1000，初始0。

## 理智与学习

| 理智范围       | 状态 | 学习收益 |
| -------------- | ---- | -------- |
| 低于−350       | 混乱 | 原版60%  |
| −350至−200以下 | 迷乱 | 原版70%  |
| −200至0以下    | 心乱 | 原版75%  |
| 0至150以下     | 恍惚 | 原版90%  |
| 150至400以下   | 动摇 | 原版100% |
| 400至600以下   | 安定 | 原版105% |
| 600至900以下   | 清醒 | 原版110% |
| 900及以上      | 专注 | 原版120% |

倍率影响课堂和读书等活动获得的科学、数学、语文和历史进度，不影响技能训练、食谱或金钱。满理智时，受到惊吓增加的恐惧减少25%，最低理智时增加25%。

与人、野兽或植物的非自愿遭遇造成创伤时，会在结束后小幅降低理智并增加恐惧，每场最多损失10点理智、增加150点基础恐惧。特殊噩梦醒后损失10点理智。怨灵侵扰、亡船袭击和诅咒等经历也会影响理智。在洞窟和港湾调查时，可以追寻异常，也可以谨慎查看、适时离开。洞窟的异常读法会带来更多惊吓，但能发现绕过积水的干路，或看懂守卫认得的手势。普通读法仍可完成调查。解除诅咒或处理袭击有助于安定心神。普通受伤不会额外损失理智，治疗创伤也不恢复理智。

## 平复恐惧

恐惧低于200时不影响意志，之后逐渐削弱意志判定，满恐惧时降至原来的75%。已有的意志成长不会减少。

恐惧达到400时，部分地点会出现**停下来调整呼吸**。花费五分钟，降低200点恐惧与少量压力，三十分钟后才能再次使用。

睡眠、休息和陪伴都能减轻恐惧。亡船袭击后，在舱口休息降低200点恐惧，与泽菲尔交谈降低100点，各限本场一次。

医院药房的镇静药降低200点恐惧，耐受较高时减半，药效未退时不叠加。药柜中的哈珀处方降低100点，精神病院处方降低200点。DoLX抗焦虑片降低150点。药物只平复恐惧，不恢复理智，原有副作用仍在。

## 恢复理智

日常活动共享**每日30点基础恢复额度**，理智600以上的恢复减半，最高可恢复至1000。恐惧的缓解不占额度，额度用尽后仍有效。

| 活动                     | 基础理智恢复 | 恐惧降低 |
| ------------------------ | ------------ | -------- |
| 睡满一小时               | 1            | 80       |
| 神殿救赎祈祷一小时       | 10           | 100      |
| 在孤儿院阁楼写作二十分钟 | 5            | 60       |
| 黯羽神社祈愿或奉纳       | 5            | 100      |
| 与月羽交谈、喝茶或散步   | 5            | 100      |
| 在绘马架还愿             | 10           | 150      |

神社祈愿与奉纳每天共用一次，奉纳更多钱不会额外恢复理智。与月羽的活动需要至少20好感。还愿每个心愿限一次。睡眠中途被打断时，不足一小时的部分没有恢复，噩梦仍会让你受惊。

同时使用**归途之书**时，共同劳动、唱诗班练习、神殿外勤、归还怨灵遗物和迷途羔羊的梦境也会影响理智或恐惧。其中日常活动的理智恢复共用上述额度。
