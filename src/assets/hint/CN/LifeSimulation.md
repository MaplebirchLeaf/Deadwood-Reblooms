### 免听凭证：条件与办理

**前置条件**：科学、数学、英语、历史均为原版 **A\***，总体成绩最高档。礼顿愿意受理，或 PC 已在原版剧情中掌握其把柄。

1. 上学日到校长办公室申请，取得礼顿同意。
2. 去贝利处取得监护人签名。仍在孤儿院时，**07:00–09:00**去办公室，通常要连续三周按时交租。
3. 罗宾反抗线让贝利离开后，去 **倒钩街公寓**找贝利，此时不再用三周交租作为签名要求。
4. **回校长办公室交表**。只有两人同意还不够，交回才正式生效。

凭证让缺课不记旷课，不会冻结成绩自然变化，也不自动授予风纪委员。礼顿把柄替代的是其私人许可，不替代四科成绩。

### 风纪委员：等级、等待与值勤

取得免听凭证 **七天后**，保持最高档总体成绩，在原版社交栏达到 **教师评价「模范学生」**和 **学校评价至少「很酷」**，再找礼顿申请。温特不需要额外推荐。

获任后，上学日 **07:00–09:00**在学校前庭值勤，每天一次。罗宾、悉尼、凯拉尔和惠特尼按当日位置参与，不保证一次遇到所有人。

| 处理方式 | 影响方向           | 操作注意               |
| -------- | ------------------ | ---------------------- |
| 维护规则 | 秩序与教职工评价   | 人物对处罚有不同态度   |
| 调停     | 关系与学生评价     | 不一定提供同样秩序收益 |
| 施压     | 强制执行与冲突     | 可能增加不满或堕落     |
| 放过     | 人物回应与秩序变化 | 不等于没有后果         |

实际变化显示在对应句子旁。获任后留堂可以自行决定是否参加，不代表全部学校责任消失。

### 公告栏、学生会长与校规

走廊 **学生事务公告栏**查看校内秩序、学生声望、教职工信任、校内堕落与值勤进度。这些是本模块的校园指标，与原版「教师」「学校」社交评价分开。

完成 **五个不同上学日**的晨间值勤，并把秩序和两类支持提升到申请要求后，找礼顿申请学生会长。重复打开同一天值勤页不算五天。

成为会长后可提出着装校规：标准校服 → 自由着装 → 暴露着装 → 自愿裸露 → 裸露日 → 强制裸露。按档推进，不是任命后直接任选最后一档。

1. 先看公告栏状态，再到校长办公室提出下一档。
2. 选择当前满足条件的正式申请、请愿或施压路线。每种方式所需支持、礼顿态度或把柄不同。
3. 更开放校规都要满足共同的校内与世界堕落条件，施压也不会绕过。
4. 进入 **七天试行**，继续维护秩序与支持，不是提案当天永久生效。
5. 七天后回办公室复核。维持不足会回退，并有 **三天冷却**，之后再准备提案。

裸露日针对星期五的校园时段，强制裸露则不是每周只有一天。已通过并保留的档位可按相应规则重新选择。

### 历史项目：先解锁哪一步

### 健身房各处怎么使用

入场后选择举重、跑步、教练伸展或临海平台慢跑。每天最多三次训练，具体耗时和效果在选项与句后提示中显示，训练通常增加疲劳，伸展可减轻压力。

- 器械训练检查手臂能否操作，双臂受缚会限制。
- 临海平台在雨天或结霜时关闭，室内与室外不是同一个入口。
- 更衣室有独立储物柜，使用原版衣柜界面，票到期后仍可在营业时间取回衣物。
- 洗手池为已入场玩家提供每日一次清洗。

#### 教练指导与训练习惯

在训练区选择「请教练安排训练」。每天可以请教一次，需要有效入场资格、衣着合适、双臂能够活动，而且当天还有训练次数。

教练会自我介绍，并保存你的训练记录。举重、室内跑步、临海慢跑和伸展只有完成后才记入记录，离开后再来仍会遇见同一位教练。跑步较少时，教练会建议补上跑步，平时则安排举重。疲劳较高、疼痛明显或一周没来训练时，会先建议伸展。

当天按建议完成对应项目，会获得少量额外的体能、运动提升，或伸展带来的压力减轻。按建议锻炼仍占用正常训练次数，额外效果每天只生效一次。随着完成的训练增多，教练会从带你熟悉器械，转为直接查看之前的记录。

### 神殿武器：借取、目标与效果

先通过原版神殿借到鞭子或短棍，一次只借一件。进入 **非自愿、非吞食**的非人类非动物触手遭遇，使用空闲且未受缚的手。

1. 在左／右手目标选择中切到触手类目标。
2. 选择具体一条触手、藤蔓、树根、嫩芽或卷须。
3. 选择「挥鞭」或「挥棍」。混合遭遇如幽灵、植物人的触手也可作为目标，不攻击其本体。
4. 命中产生固定加比例伤害，熟练度越高效果越好，但低于原版天使放逐的基础伤害。

每次命中增长原版对应武器熟练度并增加少量疲劳，不新增技能。两只手都选武器动作仍只攻击一次，不开放人类、动物或自愿互动的武器攻击。

校园查成绩、原版评价、交表与等待天数，校规查试行和支持。历史查画作讨论、期限及调查顺序。健身查营业、入场、天气和当天训练。武器查是否借到、手是否空闲、当前具体目标与遭遇类型。

### 医院药片

启用「模拟人生」并重载后，医院药房出售镇静药、助眠药、提神药、专注药和安神药。买回后在原版药柜中选择服用，新增药物只能手动使用。

- **镇静药**缓解压力，同时增加疲劳。
- **助眠药**增加困倦，改善睡眠中的疲劳恢复，不解除催眠或保证消除所有噩梦。
- **提神药**暂时压低疲劳，药效结束后这部分疲劳返回。
- **专注药**提高药效期间实际学习的收益，服药本身不增加成绩。
- **安神药**暂时减轻创伤负担，药效结束后恢复被压低的部分，不永久清除经历。

遵守包装上的服用间隔。过早重复服用可能形成依赖，药效尚在时再服药不会叠加或延长收益。连续多日服用也会逐渐增加依赖，明显依赖时部分药效减弱。停用后可能出现不安，随停止使用的时间逐渐减轻。

角色页的「医疗特质」说明当前药效，以及依赖对你造成的影响。留意药房包装上的说明，也不要把暂时缓解症状当作已经康复。

最近服过这些药片，或仍有依赖时，哈珀的医院诊疗会加入用药询问，每个游戏日最多一次。你可以如实说明，也可以隐瞒。哈珀会根据频繁服用、依赖程度和当前困倦作出不同回应，并记录这次回答。问诊不会立刻清除依赖，也不代替原本的处方、催眠或检查流程。

### 赌馆与牌桌

康努达图斯街的赌馆在酒吧楼上，**18:00–04:00** 营业。需偷窃技能达到 **D 级**解锁入口，还要有布莱尔办理的 **正式身份证**；只有学生证会被请下楼。

柜台可用现金或金融中心的 **借记卡** 兑换筹码，按 £1 对 £1 计价。借记卡兑换需要已开户、已办卡且存款足够。每张牌桌与老虎机共用赌馆的筹码余额；德州扑克带上桌的筹码单独计算，离桌时退回你的筹码余额。在筹码柜台选择金额与现金／银行结算方式，兑换后可继续游玩，也可将全部筹码兑回现金或同一银行账户。单次兑换最高 £10,000。离开时只结清牌桌，不自动兑现；筹码保留在赌场账户，必须在柜台手动兑回现金或银行存款。营业结束后仍可兑回。

休息区可以歇息、旁观牌局或与服务员交谈。保安会留意过道与客人的举动。

进楼后找 **马洛**（荷官，非恋人）。先跟马洛学做一小时荷官，之后就能来上班。每小时底薪 £30，正确处理牌桌上的争议可再得 £10。马洛夜里与你交谈时，也会提起你的表现。

马洛的社交属性是**信任**与**戒备**。闲聊可以增加信任，但不会让他忘掉牌桌上的问题；道歉只能略微缓和戒备，正确完成班次更有效。戒备较高时，他仍允许你按规矩玩牌，却不肯把牌桌交给你。

当晚因作弊被赶下牌桌后，可以尝试私下塞钱，请马洛再通融一次。关系已经熟悉，或曾正确完成几次班次，且没有一再被抓、戒备也未达到严重程度时，他才可能收钱。费用随当晚被抓次数提高，只收随身现金；拒绝时不扣钱。每晚只能尝试一次。收钱后仅恢复当晚入座资格，不增加信任，不清除作弊记录，也不恢复帮工资格；牌桌会更注意你，再被抓仍会禁入。

### 自家住宅的脱衣二十一点

自购房的起居室或卧室可以邀请同住的恋人玩二十一点，玩法分「只玩牌」与「输一局脱一件」。

- 赌注只计 **上装、下装、上身内衣、下身内衣**，按由外至内的顺序。外套与配饰不参与赌注。
- 每局输家各脱一件；衣物用尽即出局，剩余参与者继续，直到只剩最后一位赢家。
- 全员爆牌时无人脱衣；最高点数并列时并列的赢家都不脱衣。
- 牌桌上脱下的衣物在离桌或整场结束后穿回，不影响原版衣柜与没收状态。
- 发牌前或两局之间都可以选择 **这场只脱不做**。声明后不再出现亲密邀请，输牌不构成同意。

### 赌馆入口缺失时

赌馆不开门查营业时间；进不去先查偷窃技能是否为 D 级、是否持有正式身份证。牌桌不可用查是否在营业时段、衣着是否合格、压力是否已满。在家无法邀请对手时，检查同住的恋人是否在家；邀请两人一起玩，还要看两人是否愿意同桌。脱衣局无法开始查 PC 与恋人是否都还有赌注衣物。

### 体型成长

- **入口**：健身房训练区的「咨询体型成长计划」；医院大厅的「体型成长咨询」。健身入口需要有效入场资格。
- **健身**：主动开始计划后，在三十个不同日期完成力量训练、跑步或海风步道跑步，长大一个原版体型等级。与多伦一起跑步也计入；同一天只累计一次，伸展不计入。
- **医院**：支付 £5,000 开始两周疗程，按游戏日推进，完成后长大一个等级。沿用所选支付方式，提前停止不退款。
- **限制与停止**：一次只能进行一种计划，每次只长大一级，最多达到原版最大体型。咨询页面显示剩余天数，也可停止当前计划；已经长成的体型不会缩小。原版事件或作弊改变体型时，旧计划会结束。
- **效果**：整体体型增大；体能上限按原版体型结算，保留当前体能比例。胸部等其它身体尺寸不会随此计划改变。
